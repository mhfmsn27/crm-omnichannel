Cara A — Lokal dengan Docker

🚀
Tercepat untuk development. Satu perintah langsung jalan. Docker otomatis menyiapkan PostgreSQL, Redis, backend, dan frontend dengan hot-reload.
1
Siapkan file environment
bash
cp .env.docker .env.local

Nilai default sudah cukup untuk development. Edit jika perlu mengubah port atau kredensial.

2
Jalankan semua service
bash
docker compose up -d

Docker akan otomatis:

  • ▶ Menjalankan PostgreSQL 17 + pgvector di port 5432
  • ▶ Menjalankan Redis 7 di port 6379
  • ▶ Inisialisasi schema DB dari init_db_v2.sql
  • ▶ Menjalankan backend di port 8998 (hot-reload)
  • ▶ Menjalankan frontend di port 3000 (Vite dev server)
3
Jalankan migrasi fitur terbaru
bash
docker compose exec backend psql \
  -h localhost -U omni_user -d omni_db \
  -f /app/migration_features_v2.sql
ℹ️
Menambahkan tabel: Auto-Assignment, Working Hours, Outbound Webhooks, Ticket & SLA.
4
Akses aplikasi
🌐
Frontend App
http://localhost:3000
⚙️
Backend API
http://localhost:8998

Perintah Docker yang berguna

📋 Log real-time backend
docker compose logs -f backend
🔄 Restart backend saja
docker compose restart backend
🐚 Masuk shell container
docker compose exec backend sh
⏹️ Hentikan semua service
docker compose down
🗑️ Reset total (hapus database)
docker compose down -v

Nginx & SSL

⚠️
Header WebSocket wajib ada! Tanpa header Upgrade dan Connection, fitur real-time chat dan scan QR code tidak akan berfungsi.
nginx — /etc/nginx/sites-available/omnichannel
server {
    server_name domain-anda.com;
    client_max_body_size 50M;

    location / {
        proxy_pass http://localhost:8998;

        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # WebSocket — WAJIB untuk Socket.IO
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_cache_bypass $http_upgrade;

        proxy_read_timeout 300;
        proxy_connect_timeout 300;
    }

    location ~ /\. { deny all; }
}
bash — aktifkan konfigurasi
sudo ln -s /etc/nginx/sites-available/omnichannel /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t            # test konfigurasi
sudo systemctl restart nginx

Install SSL dengan Let's Encrypt

bash
sudo apt install certbot python3-certbot-nginx -y
sudo certbot --nginx -d domain-anda.com

Certbot akan otomatis memperbarui konfigurasi Nginx dan mengatur auto-renewal SSL.

Troubleshooting

Cek log PM2 untuk melihat pesan error:

bash
pm2 logs omni-backend --lines 50

# Pastikan PORT tidak bentrok
sudo lsof -i :8998

bcrypt perlu dikompilasi dari source di lingkungan Linux:

bash
cd /var/www/omnichannel/backend
rm -rf node_modules package-lock.json
npm install
npm rebuild bcrypt --build-from-source
bash
# Test koneksi manual
psql -h localhost -U omni_user -d omni_db -c "SELECT 1;"

# Pastikan PostgreSQL berjalan
sudo systemctl status postgresql

# Cek DATABASE_URL di .env
grep DATABASE_URL /var/www/omnichannel/backend/.env
⚠️
Perhatian: Langkah ini menghapus semua data. Gunakan hanya untuk instalasi baru.
sql — reset database
sudo -u postgres psql <<EOF
SELECT pg_terminate_backend(pid)
FROM pg_stat_activity
WHERE datname = 'omni_db' AND pid <> pg_backend_pid();
DROP DATABASE IF EXISTS omni_db;
DROP USER IF EXISTS omni_user;
CREATE USER omni_user WITH PASSWORD 'GantiPasswordAman!';
CREATE DATABASE omni_db;
ALTER USER omni_user WITH SUPERUSER;
GRANT ALL PRIVILEGES ON DATABASE omni_db TO omni_user;
\c omni_db
CREATE EXTENSION IF NOT EXISTS vector;
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
EOF

# Import ulang
psql -h localhost -U omni_user -d omni_db -f init_db_v2.sql
psql -h localhost -U omni_user -d omni_db -f migration_ai_provider.sql
psql -h localhost -U omni_user -d omni_db -f migration_features_v2.sql
bash
sudo systemctl status redis-server
sudo systemctl restart redis-server
redis-cli ping   # harus jawab: PONG

Project menggunakan eslint --max-warnings 0 sehingga build akan gagal jika ada unused import:

bash
# Lihat error ESLint secara detail
npm run lint

# Bersihkan cache dan install ulang
rm -rf node_modules package-lock.json
npm install
npm run build

Pastikan konfigurasi Nginx menyertakan header WebSocket:

nginx
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
proxy_cache_bypass $http_upgrade;
ℹ️
Di production, Socket.IO membutuhkan wss:// (HTTPS). Pastikan SSL sudah aktif via Certbot.

Pastikan LICENSE_KEY sudah diisi di backend/.env dan backend sudah di-restart:

bash
# Cek apakah LICENSE_KEY ada di .env
grep LICENSE_KEY /var/www/omnichannel/backend/.env

# Restart backend setelah edit .env
pm2 restart omni-backend
pm2 logs omni-backend --lines 20

Variabel VITE_* di frontend tidak ter-embed dengan benar. Pastikan semua variabel ada di frontend/.env dan frontend sudah di-build ulang:

bash
# Cek isi frontend .env
cat /var/www/omnichannel/frontend/.env

# Build ulang setelah perubahan .env
cd /var/www/omnichannel/frontend
npm run build
pm2 reload omni-backend
ℹ️
Variabel VITE_* di-embed ke dalam file JavaScript saat build. Mengubah .env tanpa build ulang tidak akan berpengaruh.
bash
# Test URL webhook bisa diakses publik
curl -I https://domain-anda.com/webhook/wa-gateway

# Monitor log incoming webhook
pm2 logs omni-backend | grep "Webhook"
