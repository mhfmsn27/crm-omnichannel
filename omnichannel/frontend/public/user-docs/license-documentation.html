🛡️ Sistem Lisensi Kriptografis RSA-2048 & Logic Binding

Proteksi lisensi 1-domain resmi pembeli berbasis Kriptografi Kunci Asimetris (RSA-2048), HMAC Anti-Tamper, 7-Day Offline Grace Period, & Logic Binding.

💡
Model Bisnis: Jual Lepas (99% Open Source Bebas Kustomisasi)

Source code backend dan frontend tetap bersih dan bebas diedit oleh pembeli tanpa enkripsi binary/obfuskasi, namun aplikasi terkunci secara matematis hanya pada 1 domain resmi pembeli.

1. Arsitektur Kunci Asimetris (RSA-2048)

Sistem menggunakan sepasang kunci kriptografi matematis:

  • Private Key (Kunci Privat) — Disimpan 100% rahasia di komputer lokal author. Digunakan untuk menandatangani domain pembeli baru. Kunci ini tidak pernah diunggah ke server klien.
  • Public Key (Kunci Publik) — Ditanam di dalam file src/config/license.js. Kunci ini hanya bertugas memverifikasi keaslian signature dan secara matematis mustahil dipakai memalsukan lisensi domain baru.

2. Cryptographic Logic Binding (Anti-Bypass)

Mencegah pembeli nakal atau cracker membongkar sistem dengan menghapus middleware lisensi:

  1. Setiap kali request diproses, sistem menurunkan token operasi unik via deriveOperationKey('wa_dispatch') berbasis domain sah & signature RSA.
  2. Engine pengiriman pesan WhatsApp (messageController.js) dan background queue memvalidasi token operasi dan stempel checksum pesan.
  3. Jika middleware lisensi sengaja dihapus, token operasi menjadi tidak sah dan engine pengiriman pesan otomatis menolak eksekusi.

3. HMAC Anti-Tamper & 7-Day Offline Grace Period

🔒

HMAC-SHA256 Sealed Cache

Hasil validasi disimpan di memori dengan digest HMAC. Jika cache dimodifikasi secara ilegal, sistem otomatis menolaknya.

⏰

7-Day Offline Grace Period

Jika Google Sheets down atau internet VPS terputus sementara, aplikasi tetap berjalan normal selama 7 hari berdasarkan verifikasi sah terakhir.

4. Cara Menerbitkan Lisensi Klien (Author Tool)

Author dapat membuat lisensi pembeli baru dalam hitungan detik melalui terminal:

node scripts/generate-license.js tokoklien.com --client="PT Klien Maju"

Output terminal akan menghasilkan baris CSV 4 kolom:

tokoklien.com,CRMHUB-MTDVEM2E-9BC16184,"C7hw5qoJFyYXBIbhGvqCAWWVg...","PT Klien Maju"

Salin baris CSV tersebut dan tempelkan pada baris baru di Google Spreadsheet Lisensi Anda.

5. Zero Dev Friction Whitelist

Untuk kenyamanan tim developer, sistem otomatis membuka akses penuh tanpa perlu cek ke Google Sheets saat berjalan di:

  • localhost, 127.0.0.1, ::1, 0.0.0.0
  • Domain lokal pengujian: *.test, *.local, *.internal
  • Saat mode NODE_ENV=development atau ALLOW_ALL_LICENSE=true
