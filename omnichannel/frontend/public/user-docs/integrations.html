🛍️ Integrasi 10+ Channel & Marketplace

Hubungkan WhatsApp, Shopee, Tokopedia, TikTok Shop, Instagram, Messenger, LINE, Telegram, Email, dan Webchat ke dalam satu Unified Inbox.

Semua integrasi channel dikelola melalui menu Integrations di sidebar. Setelah terhubung, seluruh percakapan pelanggan akan disinkronkan secara real-time ke dalam Unified Inbox CRMHUB.

🛍️ Shopee Seller Chat Bridge (Open Platform V2)

Balas chat pembeli toko Shopee Anda langsung dari Unified Inbox tanpa perlu bolak-balik membuka Shopee Seller Centre.

  1. Buka Integrations → Shopee Integration di CRMHUB.
  2. Login ke Shopee Open Platform Console dan buat App bertipe "Customer Service / Chat".
  3. Masukkan Partner ID dan Partner Key ke formulir pengaturan CRMHUB.
  4. Klik "Hubungkan Toko Shopee (Authorize)" untuk menyetujui izin toko Anda.
  5. Salin URL Webhook yang diberikan (https://domain-anda.com/webhook/shopee) dan tempelkan ke kolom Webhook URL di Shopee Open Platform.
  6. Pesan dari customer Shopee akan langsung masuk ke Unified Inbox dengan badge logo Shopee oranye.

🟢 Tokopedia Seller Chat Bridge (GoTo Open API)

Integrasi obrolan toko Tokopedia resmi via GoTo Open API OAuth 2.0.

  1. Buka Integrations → Tokopedia Integration.
  2. Siapkan kredensial dari Developer Console Tokopedia: Client ID, Client Secret, dan Fulfillment Service ID (FS ID).
  3. Masukkan kredensial ke CRMHUB dan klik "Simpan & Autentikasi".
  4. Daftarkan Webhook URL CRMHUB (https://domain-anda.com/webhook/tokopedia) pada pengaturan Webhook Tokopedia Seller Chat.
  5. Chat pembeli Tokopedia akan langsung muncul di inbox dengan badge hijau Tokopedia.

🎵 TikTok Shop & Direct Messaging (CS API)

Kelola percakapan toko TikTok Shop dan Direct Message pelanggan TikTok dalam satu inbox terpadu.

  1. Buka Integrations → TikTok Shop.
  2. Masukkan App Key, App Secret, dan Shop Cipher dari TikTok Shop Partner Center.
  3. Daftarkan Webhook Callback: https://domain-anda.com/webhook/tiktok dengan signature verification HMAC-SHA256 aktif.
  4. Selesai — seluruh chat toko TikTok otomatis tersinkronisasi.

💬 LINE Official Account (Messaging API)

Hubungkan akun LINE Official Account (LINE OA) resmi perusahaan Anda.

  1. Buka Integrations → LINE Integration.
  2. Buka LINE Developers Console dan pilih Channel Messaging API Anda.
  3. Salin Channel ID, Channel Secret, dan buat Long-Lived Channel Access Token.
  4. Tempelkan ke CRMHUB dan simpan.
  5. Salin Webhook URL CRMHUB (https://domain-anda.com/webhook/line) ke LINE Developers Console dan aktifkan opsi "Use Webhook".

📧 Email Two-Way Inbox (SMTP & IMAP / Resend)

Membaca dan membalas email pelanggan layaknya percakapan chat interaktif.

  1. Buka Integrations → Email Integration.
  2. Pilih penyedia: SMTP / IMAP Standar (cPanel/Google Workspace) atau Resend API.
  3. Masukkan host, port (misal SMTP 465/587, IMAP 993), email, dan App Password.
  4. Klik "Uji Koneksi & Simpan". Email masuk akan otomatis dibuatkan room percakapan di Unified Inbox.

🟢 WhatsApp via QR Scan (Baileys Engine)

Hubungkan nomor WhatsApp personal maupun bisnis menggunakan multi-device Baileys Gateway tanpa biaya langganan API Meta.

  1. Buka Integrations → WhatsApp Device.
  2. Klik "+ Tambah Perangkat" dan beri nama (contoh: "CS Sales 1").
  3. QR Code akan tampil di layar. Buka WhatsApp di smartphone Anda.
  4. Pilih Perangkat Tertaut → Tautkan Perangkat, lalu scan QR Code.
  5. Status otomatis berubah menjadi Terhubung.

🌐 Webchat Widget 2.0

Widget live chat modern untuk website dengan fitur Pre-Chat Lead Qualification Form dan tombol WhatsApp Handoff.

  1. Buka Integrations → Webchat Widget.
  2. Sesuaikan tema warna korporat, pesan sambutan, form pengumpulan data prospek (Nama, WhatsApp, Email).
  3. Salin kode embed JavaScript yang disediakan dan tempelkan ke website Anda sebelum tag </body>.
