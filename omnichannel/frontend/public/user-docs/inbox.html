💬 Inbox & Chat

Pusat komunikasi omnichannel Anda — kelola semua percakapan dari WhatsApp, Instagram, Messenger, Telegram, dan Webchat dalam satu tampilan terpadu.

💡
Fitur Utama CRMHUB

Inbox adalah jantung dari CRMHUB. Semua pesan masuk dari berbagai channel terpusat di sini sehingga tim Anda tidak perlu berpindah-pindah aplikasi.

Tampilan & Layout Inbox

Inbox terbagi menjadi tiga panel utama:

📋

Panel Kiri — Daftar Percakapan

Semua percakapan aktif, lengkap dengan nama kontak, preview pesan terakhir, waktu, dan indikator channel.

💬

Panel Tengah — Area Chat

Riwayat percakapan lengkap dengan bubble pesan, status terkirim/dibaca, dan input pesan di bagian bawah.

👤

Panel Kanan — Info Kontak

Detail profil kontak, label, catatan agent, deals terkait, dan riwayat interaksi.

Daftar Percakapan

Pencarian Percakapan

Klik ikon 🔍 di bagian atas daftar percakapan untuk mencari berdasarkan nama kontak atau nomor telepon. Pencarian berlaku secara real-time saat Anda mengetik.

Filter Lanjutan

Klik ikon Filter untuk memfilter percakapan berdasarkan:

  • Channel (WhatsApp, Instagram, Messenger, Telegram, Webchat)
  • Label percakapan
  • Agent yang ditugaskan
  • Status percakapan
  • Tingkat urgensi

Membaca & Mengirim Pesan

Jenis Pesan yang Didukung

📝

Teks

Pesan teks biasa, mendukung emoji dan format teks dasar.

🖼️

Gambar

Kirim foto/gambar langsung dari kamera atau galeri.

📄

Dokumen

PDF, Word, Excel, dan format file lainnya.

🎵

Audio/Voice

Pesan suara atau file audio.

📍

Lokasi

Bagikan lokasi via Google Maps.

🎬

Video

Kirim file video (ukuran tergantung batas channel).

Cara Mengirim Pesan

  1. Klik percakapan dari daftar kiri untuk membukanya.
  2. Ketik pesan di kolom input bawah.
  3. Klik ikon lampiran (📎) untuk mengirim file, gambar, atau dokumen.
  4. Tekan Enter atau klik tombol kirim (➤) untuk mengirim.

Quick Reply

Ketik / (garis miring) di kolom pesan untuk menampilkan daftar quick reply yang sudah disimpan. Klik salah satu untuk langsung memasukkannya ke kolom pesan.

⚡
Tip Produktivitas

Simpan balasan yang sering digunakan sebagai Quick Reply agar tidak perlu mengetik ulang. Buat di menu Templates → Quick Reply.

Memulai Percakapan Baru

  1. Klik tombol + (Buat Baru) di bagian atas daftar percakapan.
  2. Pilih kontak dari daftar atau masukkan nomor telepon baru.
  3. Pilih perangkat/channel yang akan digunakan untuk mengirim pesan pertama.
  4. Tulis pesan dan kirim. Percakapan baru akan muncul di daftar.
⚠️
Perhatian untuk WhatsApp Cloud API

Untuk memulai percakapan baru via WhatsApp Cloud API (Official), Anda harus menggunakan Template Pesan yang sudah disetujui Meta. Pesan bebas hanya bisa dikirim jika kontak sudah lebih dulu mengirim pesan dalam 24 jam terakhir.

Me-resolve & Membuka Kembali Percakapan

Klik tombol ✓ Selesaikan di bagian atas chat untuk me-resolve. Untuk membuka kembali percakapan yang sudah resolved, klik tab Diselesaikan di daftar kiri, pilih percakapannya, lalu klik Buka Kembali.

Panel Info Kontak (Kanan)

Panel kanan menampilkan semua informasi terkait kontak yang sedang aktif. Klik ikon ⓘ di pojok kanan atas untuk membuka/menutup panel ini.

Informasi yang Tersedia

👤

Profil Kontak

Nama, nomor telepon, email, foto profil, dan custom field lainnya.

🏷️

Label

Label yang ditambahkan ke percakapan ini.

📝

Catatan Agent

Catatan internal yang hanya bisa dilihat oleh tim (tidak terlihat kontak).

🔄

Pipeline & Deal

Deal CRM yang terhubung dengan kontak ini.

📦

Cek Ongkir

Cek ongkos kirim langsung dari panel kontak tanpa keluar inbox.

🕐

Riwayat

Histori percakapan sebelumnya dengan kontak yang sama.

Menambah Catatan Agent (Internal Note)

  1. Di panel kanan, klik tab Catatan.
  2. Klik + Tambah Catatan.
  3. Ketik catatan internal Anda (misalnya: "Kontak ini pernah komplain soal pengiriman, tangani dengan hati-hati").
  4. Klik Simpan. Catatan ini hanya terlihat oleh tim, tidak oleh kontak.

Menugaskan ke Agent

  1. Buka percakapan yang ingin ditugaskan.
  2. Di bagian atas chat, klik dropdown Tugaskan ke... atau gunakan menu ⋮ → Tugaskan ke Agent.
  3. Pilih nama agent dari daftar yang muncul. Hanya agent yang sedang Online yang ditampilkan terlebih dulu.
  4. Agent yang ditugaskan akan mendapat notifikasi dan percakapan akan muncul di tab Saya milik agent tersebut.
✨
Auto Assignment

Aktifkan fitur Auto Assignment di Settings → Auto Assignment agar sistem mendistribusikan chat secara otomatis dengan metode Round Robin atau Load Balancing tanpa perlu assign manual.

Label Percakapan

Label membantu mengkategorikan percakapan agar mudah difilter dan dilaporkan.

  1. Buka percakapan, lalu klik ikon 🏷️ Label di bagian atas chat.
  2. Pilih satu atau lebih label dari daftar (misalnya: Komplain, Order, Prospek).
  3. Label langsung tampil di daftar percakapan dan bisa digunakan sebagai filter.

Kelola daftar label di Contacts → Label Management.

Forward Pesan

Teruskan pesan tertentu ke percakapan atau kontak lain, berguna saat perlu eskalasi ke tim lain.

  1. Hover pada pesan yang ingin di-forward, lalu klik ikon ↪ Forward yang muncul.
  2. Pilih kontak tujuan atau nomor baru di modal yang muncul.
  3. Pilih perangkat pengirim, lalu klik Kirim.

Simpan ke Knowledge Base

Ubah percakapan yang bermanfaat menjadi data training untuk Chatbot AI Anda.

  1. Klik menu ⋮ → Simpan ke Knowledge Base pada percakapan.
  2. Pilih bagian percakapan yang ingin disimpan.
  3. Tambahkan tag atau kategori jika diperlukan.
  4. Klik Simpan. Data ini akan langsung tersedia sebagai konteks untuk chatbot.

Kustomisasi Wallpaper Chat

Ubah tampilan latar belakang area chat sesuai selera Anda. Klik ikon ⚙️ di bagian atas chat, lalu pilih Ganti Wallpaper. Tersedia preset warna dan gambar, atau masukkan URL gambar kustom.

Notifikasi Pesan Masuk

CRMHUB mengirimkan notifikasi real-time ketika ada pesan masuk baru:

  • Notifikasi browser — muncul di sudut layar saat tab tidak aktif
  • Badge angka — jumlah pesan belum dibaca di ikon browser dan sidebar
  • Notifikasi push mobile — jika menggunakan aplikasi mobile (memerlukan Firebase FCM aktif)
  • Bunyi notifikasi — suara masuk untuk setiap pesan baru
⚠️
Izin Notifikasi Browser

Saat pertama kali membuka CRMHUB, browser akan meminta izin notifikasi. Klik Izinkan agar tidak melewatkan pesan masuk penting.

Tips Penggunaan Inbox

🚀
Praktik Terbaik
  • Gunakan tab Saya untuk fokus pada percakapan yang menjadi tanggung jawab Anda.
  • Segera resolve percakapan yang sudah selesai agar inbox tetap bersih.
  • Manfaatkan Quick Reply untuk pertanyaan yang sering muncul — hemat 70% waktu pengetikan.
  • Aktifkan status Online saat Anda siap menerima percakapan agar Auto Assignment berjalan.
  • Gunakan Label secara konsisten agar laporan dan filter lebih akurat.
