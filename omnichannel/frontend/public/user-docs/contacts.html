Import Kontak via CSV

Import massal adalah cara paling cepat untuk menambahkan ratusan atau ribuan kontak sekaligus. Ikuti langkah berikut:

  1. Siapkan file CSV

    File CSV harus memiliki kolom minimal: name, phone. Pastikan nomor menggunakan format internasional (contoh: 628123456789 tanpa tanda +).

  2. Buka halaman Contacts

    Navigasikan ke Contacts → All Contacts.

  3. Klik tombol Import CSV

    Upload file CSV Anda dan pilih mapping kolom yang sesuai.

  4. Tetapkan Label (opsional)

    Tambahkan label ke semua kontak yang diimport sekaligus untuk memudahkan segmentasi.

  5. Konfirmasi Import

    Review jumlah kontak yang akan diimport dan klik Mulai Import. Sistem akan memproses file dan memberi tahu jika ada nomor yang tidak valid.

⚠️
Format Nomor Telepon

Pastikan semua nomor dalam format internasional tanpa tanda + atau spasi. Contoh benar: 628123456789. Nomor yang tidak valid akan dilewati saat import dan ditampilkan dalam laporan error.

Manajemen Label

Label adalah cara paling efektif untuk mengelompokkan dan mensegmentasi kontak Anda. Label yang sudah dibuat dapat digunakan sebagai filter saat membuat broadcast campaign.

Contoh label yang umum digunakan:

LabelKegunaanContoh Penggunaan
Customer Pelanggan aktif yang sudah pernah transaksi Broadcast promo loyalitas pelanggan lama
Reseller Mitra reseller atau agen penjualan Update harga grosir dan info stok terbaru
VIP Pelanggan premium dengan nilai transaksi tinggi Penawaran eksklusif dan early access produk baru
Leads Calon pelanggan yang belum bertransaksi Broadcast nurturing untuk konversi menjadi pembeli

Cara Membuat Label Baru

  1. Buka Contacts → klik Label Management.
  2. Klik Tambah Label dan masukkan nama label beserta warna yang diinginkan.
  3. Simpan. Label baru siap digunakan untuk menandai kontak.

Pencarian & Filter Kontak

Gunakan kombinasi fitur pencarian dan filter untuk menemukan segmen kontak yang tepat:

  • Cari berdasarkan nama atau nomor WhatsApp
  • Filter berdasarkan satu atau beberapa label sekaligus
  • Filter berdasarkan tanggal penambahan kontak
  • Filter berdasarkan status (aktif / tidak aktif)

Menambah Kontak Secara Manual

Selain import CSV, Anda bisa menambahkan kontak satu per satu langsung dari halaman Kontak:

  1. Buka menu Contacts di sidebar.
  2. Klik tombol "+ Tambah Kontak" di pojok kanan atas.
  3. Isi data kontak:
    • Nama — nama lengkap kontak
    • Nomor WhatsApp — format internasional tanpa + (contoh: 628123456789)
    • Email (opsional)
    • Perusahaan (opsional)
    • Label — pilih satu atau lebih label yang relevan
  4. Klik Simpan. Kontak langsung tersedia di database.

Custom Field Kontak

Custom Field memungkinkan Anda menyimpan informasi tambahan yang spesifik untuk bisnis Anda — misalnya nomor pelanggan, kota, tipe membership, atau preferensi produk.

Cara Membuat Custom Field

  1. Buka Settings → Workspace, scroll ke bagian Custom Field Kontak.
  2. Klik "+ Tambah Field".
  3. Beri nama field (contoh: "Kota", "Tipe Pelanggan", "Nomor Membership").
  4. Pilih tipe data: Teks, Angka, atau Tanggal.
  5. Simpan. Field baru akan muncul di form kontak dan saat import CSV.

Mengisi Custom Field pada Kontak

Setelah field dibuat, buka detail kontak manapun dan scroll ke bagian Custom Fields untuk mengisi nilainya. Saat import CSV, buat kolom dengan nama yang sama persis dengan nama custom field Anda.

ℹ️
Variabel Personalisasi Broadcast

Nilai custom field bisa digunakan sebagai variabel di pesan broadcast. Contoh: jika Anda punya field "Nama Toko", gunakan {{nama_toko}} dalam teks broadcast untuk menyapa setiap kontak dengan nama toko mereka masing-masing.

Operasi Massal (Bulk Actions)

Kelola banyak kontak sekaligus menggunakan fitur bulk action — lebih efisien dibanding mengubah satu per satu.

Cara Melakukan Bulk Action

  1. Di halaman Contacts, centang kotak di sebelah kiri nama kontak untuk memilih kontak yang diinginkan. Untuk memilih semua, centang kotak di header tabel.
  2. Setelah memilih satu atau lebih kontak, toolbar bulk action akan muncul di bagian atas tabel.
  3. Pilih aksi yang ingin dilakukan:
Aksi MassalFungsi
Tambah LabelTempelkan satu atau lebih label ke semua kontak yang dipilih sekaligus
Hapus LabelLepas label tertentu dari semua kontak yang dipilih
Hapus KontakHapus permanen semua kontak yang dipilih dari database
Export DipilihExport hanya kontak yang dipilih ke file CSV
⚠️
Penghapusan Permanen

Kontak yang dihapus secara massal tidak bisa dipulihkan. Pastikan Anda sudah yakin sebelum mengkonfirmasi penghapusan.

Export Kontak (CSV)

Export seluruh database kontak Anda ke file CSV untuk backup, analisis di spreadsheet, atau integrasi ke sistem lain.

  1. Buka halaman Contacts.
  2. Gunakan filter untuk mempersempit kontak yang ingin di-export (opsional — biarkan tanpa filter untuk export semua).
  3. Klik tombol "Export CSV" di toolbar atas.
  4. File CSV akan otomatis diunduh berisi data nama, nomor WA, email, tags, dan custom fields.

📱 2-Way Mobile vCard 3.0 (.vcf) Sync Stream

Sinkronisasi kontak pelanggan CRMHUB langsung ke buku telepon smartphone Android & iPhone tim sales Anda.

📇

Format vCard 3.0 Standar

File .vcf kompatibel dengan Google Contacts, Apple Contacts, dan buku telepon Android.

📞

Identifikasi Penelepon

Saat pelanggan menelepon nomor seluler sales biasa, nama dan perusahaan otomatis muncul di layar HP.

  1. Di halaman Contacts, klik tombol "Sync ke Smartphone (vCard .vcf)".
  2. Unduh file crmhub_contacts.vcf ke HP Anda.
  3. Buka file di smartphone dan pilih "Impor ke Kontak / Google Account". Seluruh kontak pelanggan kini tersimpan rapi di HP.
