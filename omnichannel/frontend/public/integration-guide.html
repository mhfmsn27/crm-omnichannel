Setup Meta App ID (Wajib untuk Messenger & Instagram)

Prasyarat Dilakukan oleh: Super Admin Satu kali setup
🚨
Harus dikonfigurasi terlebih dahulu! Sebelum siapapun bisa menghubungkan Facebook Messenger atau Instagram, Super Admin wajib mengisi App ID dan App Secret dari Meta Developer Console ke dalam pengaturan CRMHUB. Tanpa ini, tombol Connect akan menampilkan error.
💡
Satu App untuk Semua: Satu Facebook App dapat digunakan untuk Messenger, Instagram, dan WhatsApp API sekaligus. Anda tidak perlu membuat app terpisah untuk setiap channel.
Fase A — Daftar & Login ke Meta for Developers
1
Buka Meta for Developers

Kunjungi developers.facebook.com di browser. Login menggunakan akun Facebook pribadi Anda — akun ini akan menjadi pemilik/admin app.

Gunakan akun Facebook yang sudah terverifikasi dan aktif. Akun baru atau akun yang baru saja dibuat mungkin dibatasi.

2
Klik "My Apps" di pojok kanan atas

Setelah login, klik menu "My Apps" → akan tampil daftar aplikasi Anda (kosong jika baru pertama kali).

Fase B — Buat Facebook App Baru
3
Klik "Create App"

Di halaman My Apps, klik tombol hijau "Create App".

4
Pilih use case: "Other"

Meta akan menampilkan beberapa pilihan use case. Pilih "Other" untuk mendapat kontrol penuh atas produk yang ingin ditambahkan.

5
Pilih tipe app: "Business"

Pada langkah berikutnya, pilih tipe "Business". Tipe ini diperlukan untuk akses ke Messenger API, Instagram API, dan WhatsApp API.

6
Isi detail app
  • App Name — nama internal, contoh: CRMHUB Production
  • App Contact Email — email bisnis Anda
  • Business Account — pilih Meta Business Suite Anda (opsional di tahap ini)
7
Klik "Create App" — App berhasil dibuat

Anda akan diarahkan ke dashboard App. Di bagian atas terlihat App ID Anda (angka panjang). Catat App ID ini.

Fase C — Tambahkan Produk ke App
⚠️
Tambahkan semua produk berikut sekaligus agar satu App bisa digunakan untuk Messenger, Instagram, dan WhatsApp.
8
Tambahkan Facebook Login

Di dashboard App, scroll ke bagian "Add Products to Your App". Cari "Facebook Login" → klik Set Up. Pilih platform Web.

Di halaman Facebook Login → Settings, isi:

  • Valid OAuth Redirect URIs: https://DOMAIN-ANDA.com/
  • Aktifkan: Client OAuth Login = Yes
  • Aktifkan: Web OAuth Login = Yes

Ganti DOMAIN-ANDA.com dengan domain production CRMHUB Anda.

9
Tambahkan Messenger

Klik "Add Product" di sidebar kiri → cari "Messenger" → klik Set Up.

Di halaman Messenger Settings:

  • Di bagian "Access Tokens", hubungkan Facebook Page Anda untuk mendapat token sementara (untuk testing).
  • Konfigurasi Webhooks akan dilakukan di Fase D.
10
Tambahkan Instagram Graph API

Klik "Add Product" → cari "Instagram" atau "Instagram Graph API" → klik Set Up.

Di halaman Instagram Settings, tambahkan akun Instagram bisnis Anda sebagai test account untuk development.

11
Tambahkan WhatsApp (jika diperlukan)

Klik "Add Product" → cari "WhatsApp" → klik Set Up. Ikuti wizard untuk menghubungkan WhatsApp Business Account (WABA).

Langkah ini hanya diperlukan jika Anda ingin menggunakan WhatsApp API Official, bukan WhatsApp QR Scan.

Fase D — Daftarkan Webhook URL di Meta
ℹ️
Webhook URL memberitahu Meta ke mana harus mengirim notifikasi pesan. CRMHUB harus sudah berjalan dan bisa diakses dari internet (bukan localhost) saat langkah ini.
12
Setup Webhook untuk Messenger

Di sidebar App, klik Messenger → Webhooks (atau di menu Messenger → Settings → Webhooks). Klik "Add Callback URL" dan isi:

  • Callback URL: https://DOMAIN-ANDA.com/webhook/messenger
  • Verify Token: reply_saas_verify

Klik Verify and Save. Meta akan mengirim request GET ke URL tersebut — jika CRMHUB merespons dengan benar, webhook tersimpan.

13
Subscribe events Messenger

Setelah webhook tersimpan, klik "Add Subscriptions" pada Page yang ingin di-subscribe. Centang events berikut:

  • ✅ messages
  • ✅ messaging_postbacks
  • ✅ messaging_read
  • ✅ message_deliveries
14
Setup Webhook untuk Instagram

Di sidebar App, klik Instagram → Webhooks. Klik "Add Callback URL" dan isi:

  • Callback URL: https://DOMAIN-ANDA.com/webhook/instagram
  • Verify Token: reply_saas_verify

Klik Verify and Save.

15
Subscribe events Instagram

Pada bagian Instagram Webhook Subscriptions, centang:

  • ✅ messages
  • ✅ messaging_postbacks
  • ✅ messaging_seen
Referensi Webhook URLs — Ganti dengan domain Anda
# Messenger Webhook
Callback URL  : https://app.crmhub.id/webhook/messenger
Verify Token  : reply_saas_verify

# Instagram Webhook
Callback URL  : https://app.crmhub.id/webhook/instagram
Verify Token  : reply_saas_verify
Fase E — Ambil App ID & App Secret
16
Buka Settings → Basic

Di sidebar kiri App dashboard, klik Settings → Basic.

17
Catat App ID

Di bagian atas halaman terdapat App ID (angka 15–16 digit). Ini yang akan diisi sebagai Messenger App ID dan Instagram App ID di CRMHUB.

18
Ambil App Secret

Di bawah App ID terdapat field App Secret yang disamarkan (******). Klik tombol "Show", lalu masukkan password Facebook Anda untuk mengungkap nilainya. Salin App Secret ini.

Jangan pernah bagikan App Secret ke siapapun. Simpan di tempat yang aman.

Nilai yang harus dicatat dari Meta Developer Console
App ID         :  1234567890123456   # untuk Messenger App ID & Instagram App ID
App Secret     :  abc123def456...    # untuk Messenger Secret & Instagram Secret
Fase F — Isi di Super Admin CRMHUB
🛡️
Langkah ini hanya bisa dilakukan oleh akun Super Admin. Pengguna biasa (Admin Organisasi) tidak memiliki akses ke menu ini.
19
Login sebagai Super Admin

Masuk ke CRMHUB dengan akun Super Admin. Pastikan role akun adalah superadmin.

20
Buka menu SuperAdmin → Settings

Di sidebar, klik menu SuperAdmin → pilih Settings. Halaman konfigurasi global sistem akan terbuka.

21
Cari section "Messenger & Instagram"

Scroll ke bawah sampai menemukan bagian berlabel "Messenger & Instagram" dengan ikon biru ⚡.

22
Isi 4 field berikut
  • Messenger App ID — isi dengan App ID dari Fase E (langkah 17)
  • Messenger Secret — isi dengan App Secret dari Fase E (langkah 18)
  • Instagram App ID — isi dengan App ID yang sama seperti Messenger App ID
  • Instagram Secret — isi dengan App Secret yang sama seperti Messenger Secret

Instagram dan Messenger menggunakan App ID yang sama karena mereka berada dalam satu Facebook App.

23
Klik "Save Settings"

Klik tombol Save atau Save Settings. Konfigurasi tersimpan ke database dan langsung aktif.

✅ Verifikasi Berhasil

  • Buka halaman Integrations → Facebook Messenger
  • Subtitle di bawah judul berubah dari "Not Set" menjadi angka App ID
  • Klik "Connect Page" — popup Facebook Login muncul tanpa error
Fase G — Mode Development vs Live
i
Mode Development (default)

Saat pertama dibuat, App berada di mode Development. Hanya akun yang ditambahkan sebagai Tester atau Developer di App dashboard yang bisa menggunakannya.

Untuk testing: buka App Dashboard → Roles → Add Testers dan tambahkan Facebook user yang perlu akses.

ii
Mode Live (untuk produksi)

Saat siap produksi (semua pengguna bisa connect), ubah mode di App Dashboard → App Mode → Switch to Live.

Untuk switch ke Live, Meta biasanya memerlukan:

  • Privacy Policy URL yang valid
  • Terms of Service URL
  • App Icon sudah diupload

Sambil menunggu review Meta (jika diperlukan), gunakan mode Development dengan akun Tester untuk semua pengguna internal.

WhatsApp (Scan QR Code)

Aktif Menu: Integrations → WhatsApp Devices Tanpa Biaya API
ℹ️
Metode ini menggunakan WhatsApp Personal atau WhatsApp Business App biasa. Tidak perlu mendaftar ke Meta atau membayar biaya API. Cocok untuk bisnis skala kecil–menengah.
Yang Dibutuhkan

Syarat & Persiapan

  • Nomor HP aktif dengan WhatsApp sudah terinstall (Personal atau Business App)
  • HP harus terhubung ke internet selama sesi aktif (bisa background)
  • Satu nomor WhatsApp hanya bisa dihubungkan ke satu device di CRMHUB
  • Pastikan WhatsApp di HP sudah diperbarui ke versi terbaru
  • Jangan log out dari WhatsApp di HP selama device terhubung
Langkah Integrasi di Aplikasi
1
Buka menu Integrations

Dari sidebar kiri aplikasi, klik menu Integrations, lalu pilih WhatsApp Devices.

2
Klik "Add New Device"

Klik kartu bergaris putus-putus bertuliskan "+ Add New Device" di bagian atas halaman.

3
Isi nama device

Di popup yang muncul, isi Device Name — gunakan nama yang mudah dikenali tim Anda.

Contoh nama: CS Utama, Sales Jakarta 1, Nomor Budi, WhatsApp Promosi

4
Klik "Create Session"

Sistem akan membuat sesi baru. Tunggu 3–5 detik hingga QR Code muncul di popup.

5
Buka WhatsApp di HP Anda

Pada HP yang ingin dihubungkan, ikuti langkah berikut sesuai jenis HP:

  • Android: WhatsApp → Menu ⋮ (titik 3) → Linked Devices → Link a Device
  • iPhone: WhatsApp → Settings → Linked Devices → Link a Device
  • WhatsApp Business: Menu ⋮ → Linked Devices → Link a Device
6
Scan QR Code

Arahkan kamera HP ke QR Code yang tampil di layar komputer. Pastikan seluruh QR Code masuk di frame kamera.

QR Code berlaku selama 60 detik. Jika kedaluwarsa, klik tombol Retry untuk refresh QR baru.

7
Tunggu konfirmasi koneksi

Setelah scan berhasil, status device berubah dari Scanning menjadi Connected ✓. Proses ini 5–15 detik.

8
Test pengiriman pesan

Klik ikon ✉️ atau tombol "Send Test Message" pada kartu device. Masukkan nomor tujuan dan pesan, klik Send. Jika berhasil, device siap digunakan.

Status Device
Connected
Device aktif dan siap menerima/mengirim pesan
Connecting / Scanning
Proses scan QR atau sinkronisasi sedang berlangsung
Disconnected
Koneksi terputus — klik Retry untuk scan ulang
Created
Sesi sudah dibuat tapi belum di-scan
Mengelola Device
▶
Rename device

Klik ikon ✏️ (Edit) pada kartu device untuk mengubah nama.

▶
Lihat laporan performa

Klik ikon 📊 pada kartu device untuk melihat statistik: pesan masuk, pesan keluar, pesan gagal hari ini, dan performa tiap agen.

▶
Hapus device

Klik ikon 🗑️ untuk menghapus device. Koneksi akan terputus dan sesi dihapus dari sistem.

Fitur yang Tersedia
🔗 Multi-Device
Hubungkan beberapa nomor WhatsApp sekaligus dalam satu akun
📨 Kirim & Terima Pesan
Teks, gambar, video, dokumen, audio, stiker
📢 Broadcast Massal
Kirim pesan ke ratusan kontak sekaligus dengan filter segmentasi
🤖 AI Chatbot
Aktifkan AI untuk membalas pesan otomatis 24/7
📊 Laporan Performa
Statistik pesan per device dan per agen secara real-time
🏷️ Auto-Assignment
Distribusi percakapan ke agen otomatis berdasarkan aturan
⚠️
Catatan Penting: Karena ini bukan API resmi Meta, ada risiko nomor terkena pembatasan jika digunakan untuk broadcast dalam jumlah sangat besar. Untuk volume tinggi, gunakan WhatsApp API Official.

WhatsApp API Official (Cloud API)

API Resmi Meta Menu: Integrations → WhatsApp API Berbayar
✅
Metode ini menggunakan WhatsApp Business API resmi dari Meta. Lebih stabil, cocok untuk volume tinggi, dan mendukung fitur template pesan terverifikasi.
Yang Dibutuhkan

Syarat & Persiapan

  • Akun Meta Business Suite (business.facebook.com)
  • Aplikasi terdaftar di Meta for Developers (developers.facebook.com)
  • Nomor telepon yang belum terdaftar di WhatsApp manapun
  • WABA ID — WhatsApp Business Account ID
  • Phone Number ID — ID nomor yang terdaftar di WABA
  • Permanent Access Token — dari Meta System User
Metode 1: Facebook Login (Disarankan)
Metode 2: Input Manual
Metode 1 — Facebook Login (Lebih Mudah)
1
Buka halaman WhatsApp API

Dari sidebar, klik Integrations → WhatsApp API.

2
Klik "Connect WhatsApp"

Pada tab Auto (Facebook Login), klik tombol biru "Connect with Facebook".

3
Login akun Facebook/Meta

Popup Facebook Login akan muncul. Masuk dengan akun Facebook yang terhubung ke Meta Business Anda.

4
Pilih Business & WABA

Pilih Meta Business yang akan dihubungkan, kemudian pilih WhatsApp Business Account (WABA) yang sudah ada atau buat baru.

5
Verifikasi nomor telepon

Pilih nomor telepon yang akan digunakan. Jika nomor baru, ikuti proses verifikasi OTP melalui SMS atau telepon.

6
Izinkan akses

Klik Continue dan Done pada dialog izin Facebook. Sistem akan otomatis mengambil WABA ID, Phone Number ID, dan Token.

7
Selesai — nomor terhubung

Kartu nomor WhatsApp API akan muncul dengan status Connected. Siap digunakan untuk mengirim template dan menerima pesan.

Metode 2 — Input Manual (BYOK)
1
Buka Meta for Developers

Kunjungi developers.facebook.com → klik My Apps → pilih aplikasi WhatsApp Anda.

2
Ambil Phone Number ID

Di sidebar kiri, klik WhatsApp → API Setup. Di bagian From, catat nilai Phone number ID.

3
Ambil WABA ID

Masih di halaman API Setup, scroll ke bawah. WABA ID terlihat di bagian WhatsApp Business Account ID, atau buka menu WhatsApp → Configuration.

4
Buat Permanent Access Token

Buka business.facebook.com → Settings → System Users → Add. Buat System User dengan role Admin. Klik Generate New Token, pilih aplikasi Anda, centang izin whatsapp_business_messaging dan whatsapp_business_management.

Simpan token ini baik-baik — token hanya ditampilkan sekali!

5
Isi form di CRMHUB

Di CRMHUB, buka Integrations → WhatsApp API, klik "Connect WhatsApp", pilih tab Manual. Isi:

  • Display Name — nama tampilan (opsional)
  • WABA ID — dari langkah 3
  • Phone Number ID — dari langkah 2
  • Permanent Access Token — dari langkah 4
6
Klik "Save & Connect"

Sistem akan memverifikasi token dan menghubungkan nomor. Jika berhasil, kartu nomor muncul dengan badge API.

Fitur yang Tersedia
📋 Template Terverifikasi
Kirim pesan template yang disetujui Meta ke kontak mana pun
⭐ Quality Rating
Pantau kualitas nomor dan reputasi pengiriman
📊 Statistik API
Laporan pengiriman, delivery rate, dan read rate
🔒 Nomor Terverifikasi
Centang hijau Meta untuk meningkatkan kepercayaan pelanggan
📢 Broadcast Volume Tinggi
Kirim ribuan pesan template tanpa risiko ban

Template Manager (WhatsApp)

Khusus API Official Menu: Integrations → Template Manager
⚠️
Template Manager hanya tersedia jika Anda sudah menghubungkan WhatsApp API Official. Pilih device API Anda dari dropdown sebelum membuat template.
Langkah Membuat Template Baru
1
Pilih device WhatsApp API

Di halaman Template Manager, klik dropdown "Select Device" dan pilih nomor WhatsApp API yang sudah terhubung.

2
Klik "Create Template"

Klik tombol "+ Create Template" di pojok kanan atas.

3
Isi informasi dasar
  • Template Name — huruf kecil, pakai underscore: promo_lebaran_2025
  • Category — pilih salah satu:
    MARKETING (promosi, penawaran) | UTILITY (konfirmasi, invoice, OTP) | AUTHENTICATION (kode verifikasi)
  • Language — Indonesian atau English
4
Atur Header (Opsional)

Pilih tipe header:

  • NONE — tanpa header
  • TEXT — teks singkat di atas pesan
  • IMAGE — unggah gambar (JPEG/PNG, maks 5MB)
  • VIDEO — unggah video (MP4, maks 16MB)
  • DOCUMENT — unggah PDF atau dokumen
5
Tulis Body Pesan

Isi teks utama pesan di kolom Body. Anda bisa menggunakan:

  • {{1}}, {{2}} — variabel dinamis (nama, nomor order, dll)
  • *teks* — teks tebal
  • _teks_ — teks miring
  • ~teks~ — teks dicoret

Contoh: "Halo {{1}}, pesanan Anda #{{2}} sudah dikirim hari ini. Terima kasih!"

6
Tambah Footer (Opsional)

Isi teks kecil di bawah pesan, contoh: Balas STOP untuk berhenti menerima pesan

7
Tambah Tombol (Maks 3)

Klik tombol untuk menambahkan:

  • + Quick Reply — tombol balasan cepat (teks saja)
  • + URL — tombol link ke website
  • + Phone — tombol telepon langsung
8
Preview & Submit

Lihat preview pesan di panel kanan (tampilan seperti HP). Jika sudah sesuai, klik "Submit to Meta".

Status Template
APPROVED
Template siap digunakan untuk broadcast dan pengiriman
PENDING
Sedang direview oleh Meta (biasanya 1–24 jam)
REJECTED
Ditolak Meta — edit isi template dan submit ulang
💡
Klik tombol "Sync Templates" untuk menarik semua template terbaru dari Meta jika ada perubahan status yang tidak ter-update otomatis.

Facebook Messenger

Aktif Menu: Integrations → Facebook Messenger Meta Graph API
Yang Dibutuhkan

Syarat Wajib

  • Akun Facebook pribadi yang merupakan Admin dari Facebook Page bisnis
  • Facebook Page sudah dibuat dan aktif (bukan profil pribadi)
  • Fitur Messenger diaktifkan di Page Settings
  • Akun Facebook pribadi harus login di browser yang sama saat proses koneksi
Langkah Integrasi
1
Pastikan Anda sudah login Facebook di browser

Buka tab baru, kunjungi facebook.com, pastikan sudah login dengan akun Admin Page yang ingin dihubungkan.

2
Buka menu Messenger Integration

Di CRMHUB, klik Integrations → Facebook Messenger.

3
Klik "Connect Page"

Klik tombol "+ Connect Page" di pojok kanan atas halaman.

4
Popup Facebook Login muncul

Popup Facebook akan terbuka. Klik "Continue as [Nama Anda]" untuk lanjut dengan akun yang sudah login.

Jika popup tidak muncul, periksa apakah browser memblokir popup. Aktifkan popup untuk domain CRMHUB.

5
Pilih Page yang akan dihubungkan

Facebook akan menampilkan daftar semua Page yang Anda admin-nya. Centang semua Page yang ingin dihubungkan ke CRMHUB. Klik "Edit Settings" jika ingin mengelola izin per-Page.

6
Berikan izin yang diminta

CRMHUB membutuhkan izin: pages_show_list, pages_messaging, pages_manage_metadata, business_management. Pastikan semua izin di-allow, bukan di-skip.

7
Klik "Done" / "OK"

Setelah semua izin disetujui, popup tertutup dan CRMHUB secara otomatis mendaftarkan webhook ke Page Anda.

8
Page terhubung!

Kartu Page akan muncul di halaman Messenger Integration dengan foto profil, nama Page, dan status Connected.

9
Test integrasi

Buka Facebook Page Anda dan kirim pesan Messenger dari akun lain. Pesan harus muncul di inbox CRMHUB dalam beberapa detik.

Mengelola Page Terhubung
▶
Toggle AI Chatbot

Aktifkan/nonaktifkan AI pada setiap Page secara terpisah dengan tombol toggle AI ON/OFF di kartu Page.

▶
Reconnect Webhook

Jika pesan tidak masuk, klik tombol "Reconnect Webhook" (🔄) untuk mendaftarkan ulang webhook ke Facebook.

▶
Disconnect Page

Klik tombol 🗑️ untuk memutus koneksi Page. Pesan baru tidak akan masuk lagi ke CRMHUB.

⚠️
Page tidak muncul? Pastikan akun Facebook yang digunakan adalah Admin dari Page tersebut. Jika pernah menolak izin sebelumnya, buka Facebook → Settings → Security → Business Integrations dan hapus izin CRMHUB, lalu hubungkan ulang.
Fitur yang Tersedia
💬 Multi-Page Inbox
Kelola pesan dari beberapa Facebook Page dalam satu inbox
🤖 AI Chatbot
Auto-reply berbasis AI dapat diaktifkan per Page
📎 Rich Media
Terima dan kirim gambar, video, file, stiker
👥 Agent Assignment
Distribusikan chat ke agen tim Anda

Persiapan Sebelum Integrasi
A
Ubah akun Instagram ke Business/Creator

Di Instagram: Profil → Menu ☰ → Settings → Account → Switch to Professional Account. Pilih Business atau Creator.

B
Hubungkan Instagram ke Facebook Page

Di Instagram: Profil → Edit Profile → Page, pilih Facebook Page Anda. ATAU di Facebook Page: Settings → Linked Accounts → Instagram → Connect Account.

Pastikan akun Facebook yang terhubung adalah akun yang sama dengan yang akan Anda gunakan untuk login di CRMHUB.

Langkah Integrasi di CRMHUB
1
Pastikan login Facebook di browser

Buka facebook.com di tab lain — pastikan sudah login dengan akun Facebook yang terhubung ke Page yang sudah di-link ke Instagram.

2
Buka menu Instagram Integration

Di CRMHUB, klik Integrations → Instagram.

3
Klik "Connect Instagram"

Klik tombol "+ Connect Instagram".

4
Login & pilih akun

Popup Facebook Login muncul. Login, lalu pilih akun Instagram yang ingin dihubungkan (hanya yang berstatus Business/Creator dan terhubung ke Facebook Page yang akan ditampilkan).

5
Berikan semua izin

Izin yang dibutuhkan: instagram_basic, instagram_manage_messages, pages_show_list, pages_manage_metadata. Jangan skip izin apapun.

6
Akun terhubung

Kartu Instagram dengan foto profil, username (@handle), dan ID akun akan muncul dengan status Connected.

7
Test

Kirim DM ke akun Instagram Anda dari akun lain. Pesan harus muncul di inbox CRMHUB.

💡
Akun tidak muncul setelah login? Periksa kembali apakah Instagram sudah terhubung ke Facebook Page (Langkah Persiapan B). Akun Instagram Personal tidak akan muncul di daftar.

Telegram Bot

Aktif Menu: Integrations → Telegram Gratis
✅
Telegram Bot API sepenuhnya gratis tanpa biaya apapun. Bisa digunakan untuk tim support, komunitas, atau layanan pelanggan berbasis Telegram.
Langkah 1 — Buat Bot di Telegram
1
Buka Telegram dan cari @BotFather

Di aplikasi Telegram (HP atau Desktop), buka pencarian dan ketik @BotFather. Pilih akun resmi dengan centang biru ✓.

2
Mulai chat dengan BotFather

Klik START atau ketik /start untuk memulai.

3
Buat bot baru

Ketik perintah: /newbot dan tekan Enter.

4
Beri nama bot

BotFather akan bertanya nama bot Anda. Ketikkan nama yang mudah dikenali, contoh: CS Toko Baju. Nama ini yang tampil di chat pelanggan.

5
Beri username bot

Ketikkan username unik yang diakhiri kata bot, contoh: cstokobaju_bot atau TokoABCSupport_bot.

Username harus unik di seluruh Telegram. Jika sudah dipakai, coba variasi lain.

6
Salin HTTP API Token

BotFather akan mengirimkan token seperti: 1234567890:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw. Salin token ini — akan digunakan di CRMHUB.

Simpan token ini dengan aman. Jangan bagikan ke orang lain karena bisa digunakan untuk mengontrol bot Anda.

Langkah 2 — Hubungkan ke CRMHUB
7
Buka menu Telegram Integration

Di CRMHUB, klik Integrations → Telegram.

8
Klik "Connect Telegram"

Klik tombol "+ Connect Telegram" di pojok kanan atas.

9

Zapier / Make.com (Webhook Otomasi)

Aktif Menu: Integrations → Zapier / Make Outbound Webhook
ℹ️
Fitur ini mengirimkan data kejadian dari CRMHUB ke aplikasi eksternal (Zapier, Make.com, Google Sheets, Slack, dll.) secara otomatis melalui outbound webhook.
Langkah Setup via Zapier
1
Buat Zap baru di Zapier

Login ke zapier.com → klik + Create Zap.

2
Pilih trigger "Webhooks by Zapier"

Di bagian Trigger, cari dan pilih "Webhooks by Zapier" → pilih event "Catch Hook".

3
Salin URL webhook dari Zapier

Zapier akan memberikan URL unik seperti: https://hooks.zapier.com/hooks/catch/xxxxx/yyyyy/. Salin URL ini.

4
Daftarkan webhook di CRMHUB

Di CRMHUB, buka Settings → Webhooks → Add Webhook. Paste URL Zapier, beri nama, lalu pilih event yang ingin di-trigger.

5
Klik "Test" di CRMHUB

Klik tombol Test — CRMHUB akan mengirim event test.ping ke Zapier.

6
Konfirmasi di Zapier & lanjutkan

Kembali ke Zapier → klik "Test Trigger". Data dari CRMHUB akan terdeteksi. Lanjutkan konfigurasi action (kirim ke Google Sheets, Slack, email, dll.).

Langkah Setup via Make.com
1
Buat Scenario baru di Make.com

Login ke make.com → klik Create a new scenario.

2
Tambahkan modul "Webhooks" → "Custom Webhook"

Pilih Webhooks dari daftar modul, lalu pilih Custom Webhook. Klik Add dan beri nama webhook Anda.

3
Salin URL webhook dari Make.com

Make akan generate URL, contoh: https://hook.eu1.make.com/xxxxx. Salin URL ini.

4
Daftarkan di CRMHUB & Test

Sama seperti Zapier: buka Settings → Webhooks → Add Webhook, paste URL Make.com, pilih event, lalu klik Test. Make.com secara otomatis mendeteksi struktur payload.

5
Tambah modul action

Setelah data terdeteksi, tambahkan modul lanjutan (Google Sheets, Slack, Gmail, CRM Anda, dll.) dan mapping field sesuai kebutuhan.

Verifikasi Keamanan (HMAC)

Setiap webhook dilengkapi header X-Reply-Signature yang bisa diverifikasi untuk memastikan request benar-benar dari CRMHUB:

Node.js — Verifikasi HMAC Signature
const crypto = require('crypto');

function verifySignature(payload, signature, secret) {
  const expected = crypto
    .createHmac('sha256', secret)
    .update(payload)
    .digest('hex');
  return `sha256=${expected}` === signature;
}

Troubleshooting Umum

Solusi untuk masalah yang sering ditemui
MasalahChannelSolusi
QR Code expired sebelum sempat di-scan WhatsApp QR Klik tombol Retry untuk generate QR baru. QR berlaku 60 detik.
Device Disconnected tiba-tiba WhatsApp QR HP mungkin mati atau kehilangan koneksi internet. Pastikan HP tetap online. Klik Retry untuk reconnect.
Pesan tidak masuk ke inbox Messenger / Instagram Klik tombol Reconnect Webhook (🔄) pada kartu Page/akun. Jika masih gagal, disconnect dan hubungkan ulang.
Facebook Page tidak muncul saat login Messenger / Instagram Pastikan akun Facebook yang digunakan adalah Admin dari Page tersebut. Cek di: facebook.com → Page → Settings → Page Roles.
Instagram tidak muncul setelah login Instagram Pastikan: (1) Akun Instagram berjenis Business/Creator. (2) Instagram sudah di-link ke Facebook Page. (3) Sama akun Facebook yang dipakai login.
Bot Telegram error / tidak aktif Telegram Token mungkin sudah expired atau di-revoke. Buka BotFather, ketik /mybots → pilih bot → API Token → Revoke current token → generate token baru dan hubungkan ulang.
Template ditolak (REJECTED) Meta WhatsApp API Review isi template — hindari konten promosi terlalu agresif, link shortener, atau klaim berlebihan. Edit dan submit ulang.
Widget webchat tidak muncul di website Webchat Periksa: (1) Kode sudah ditempel sebelum </body>. (2) Widget ID sudah benar. (3) Widget berstatus Active di CRMHUB. (4) Tidak ada content blocker aktif.
Webhook Zapier tidak menerima data Zapier / Make Pastikan webhook URL di CRMHUB Settings sudah benar dan event yang dipilih sudah aktif. Coba klik tombol Test lagi.
