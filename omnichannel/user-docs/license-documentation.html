🎯 Sistem Lisensi Baru

One-time purchase license dengan proteksi domain. Sangat simple - tinggal daftarkan domain di Google Sheets untuk mengaktifkan.

1. Gambaran Umum

✅ Prinsip Kerja

  • Domain ada di Sheets → License ACTIVE (bisa akses)
  • Domain tidak ada di Sheets → License BLOCKED (tidak bisa akses)

Simpel seperti itu. Tidak ada plan, tidak ada expiry, tidak ada tier.

Fitur

  • ✅ One-time purchase - Tidak ada biaya berulang
  • ✅ No expiry - Berlaku selamanya
  • ✅ Domain-locked - 1 license = 1 domain
  • ✅ 6h cache - Tidak cek Sheets setiap request
  • ✅ Instant disable - Hapus dari Sheets langsung nonaktif
  • ✅ Fail-safe - Jika Sheets down, tetap bisa akses dengan cache
Domain打开 aplikasi ↓ Cek Google Sheets ↓ Domain ada? ↓ Ya = AKTIF | Tidak = BLOKED

3. Setup Google Sheets

1
Buat Google Spreadsheet Baru
Buka Google Sheets dan buat spreadsheet baru.
2
Rename Sheet Tab
Rename sheet pertama menjadi licenses
3
Tambahkan Header & Data
Di baris pertama (A1), tambahkan header:
Domain | License Key
Di baris kedua (A2), tambahkan domain client:
clientdomain.com |
4
Set Sharing ke Public View
Klik Share → Anyone with the link → Viewer
5
Copy Spreadsheet ID
Copy ID dari URL spreadsheet:
https://docs.google.com/spreadsheets/d/[INI-ADALAH-SHEET-ID]/edit

📋 Template Google Sheet

Struktur spreadsheet yang benar:

Domain License Key
client1.com (kosongkan)
client2.com (kosongkan)
⚠️ Untuk Menonaktifkan License

Cukup hapus baris domain tersebut dari spreadsheet. Domain akan langsung terblokir (setelah cache expired atau refresh manual).

4. Konfigurasi Environment

Environment Variables

Tambahkan variabel berikut di file .env:

# License System Configuration LICENSE_SHEET_ID=YOUR_GOOGLE_SHEETS_ID_HERE # Production mode (penting!) NODE_ENV=production
💡 Catatan Penting

Untuk production, selalu gunakan NODE_ENV=production. Jika tidak diset, sistem akan berjalan dalam mode development (allow all).

5. Cara Penggunaan

Akses License Page

Di dashboard CRMHub:

  1. Buka menu Settings
  2. Klik License di submenu
  3. Akan tampil status license (Aktif/Invalid)

Menambah Client Baru

  1. Buka Google Spreadsheet license
  2. Tambah baris baru dengan domain client
  3. Simpan

Menonaktifkan License

  1. Buka Google Spreadsheet license
  2. Hapus baris domain client yang ingin dinonaktifkan
  3. Simpan
💡 Tips

Jika ingin menonaktifkan segera tanpa tunggu cache expire, klik tombol "Refresh" di License Page.

6. Keamanan

🛡️ Keamanan

  • ✅ Domain-locked - Tidak bisa dipindahkan ke domain lain
  • ✅ 6h Cache - Validasi tidak setiap request
  • ✅ Fail-safe - Jika Sheets down, tetap akses dengan cache
  • ✅ Instant disable - Hapus dari Sheets langsung terblokir
  • ✅ No key in client - Tidak ada license key yang tersimpan di sisi client

Mengapa Sulit di-Crack?

  • Layer 1: Domain validation dilakukan di server-side
  • Layer 2: License server di Google Sheets (di luar kontrol client)
  • Layer 3: Tidak ada license key yang bisa diexpose
  • Layer 4: Cache ter-enkripsi
