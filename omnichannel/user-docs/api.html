🔌 Developer & API

Hubungkan CRMHUB dengan sistem eksternal menggunakan Public API — kirim pesan WhatsApp, kelola kontak, dan banyak lagi secara programatik.

Developer Apps (Kelola API Key)

Sebelum menggunakan Public API, Anda perlu membuat Developer App untuk mendapatkan API Key. API Key digunakan sebagai autentikasi di semua request API.

Cara Membuat Developer App

  1. Buka menu Developer di sidebar (hanya muncul jika diaktifkan oleh Admin).
  2. Klik "+ Buat Aplikasi".
  3. Beri nama aplikasi (contoh: "Integrasi Website", "Bot Order").
  4. Isi deskripsi singkat kegunaan aplikasi.
  5. Klik Buat. API Key akan dibuat otomatis.
  6. Salin API Key yang ditampilkan — simpan di tempat aman, key hanya ditampilkan sekali.
⚠️
Keamanan API Key

Jangan pernah menyimpan API Key di kode yang bisa dilihat publik (repository GitHub, halaman web). Jika key bocor, segera buat key baru dari halaman Developer dengan klik "Regenerate Key".

Memantau Penggunaan API

Di halaman Developer → Log API, Anda dapat melihat semua request yang masuk menggunakan API Key Anda — termasuk endpoint yang dipanggil, waktu, status code, dan payload. Berguna untuk debugging integrasi.

Public API CRMHUB

CRMHUB menyediakan REST API untuk integrasi dengan sistem eksternal. Semua endpoint menggunakan format JSON.

Autentikasi

Sertakan API Key di setiap request menggunakan header:

x-api-key: YOUR_API_KEY_HERE

Base URL

https://domain-anda.com/api/public/v1/

Pagination

Endpoint yang mengembalikan banyak data mendukung pagination dengan parameter query berikut:

GET /api/public/v1/contacts?page=1&limit=50

Response:
{
  "data": [...],
  "pagination": {
    "page": 1,
    "limit": 50,
    "total": 1200,
    "total_pages": 24
  }
}

Filter Kontak

GET /api/public/v1/contacts?search=Budi&label=VIP&page=1&limit=20

Rate Limiting

API CRMHUB menerapkan rate limiting untuk menjaga stabilitas server:

EndpointLimitWindow
Kirim Pesan (/send-*)60 requestper menit
Operasi Kontak (/contacts)120 requestper menit
Operasi Percakapan (/conversations)60 requestper menit
Semua endpoint lainnya300 requestper menit

Jika melewati batas, server mengembalikan status 429 Too Many Requests. Header Retry-After menunjukkan berapa detik lagi sebelum bisa request kembali.

💡
Best Practice Rate Limiting

Gunakan queue dan delay di aplikasi Anda saat mengirim banyak pesan. Jangan mengirim semua pesan sekaligus — kirim dengan jeda minimal 1 detik per pesan untuk menghindari rate limit dan menjaga nomor WA tetap aman.

Webhook Outbound (Menerima Event)

Webhook Outbound memungkinkan CRMHUB mengirimkan notifikasi real-time ke URL endpoint sistem Anda setiap kali terjadi event tertentu.

Event yang Tersedia

EventKapan Dikirim
message.receivedPesan baru masuk dari pelanggan
message.sentPesan berhasil dikirim ke pelanggan
conversation.createdPercakapan baru dibuat
conversation.resolvedPercakapan di-resolve
contact.createdKontak baru ditambahkan

Contoh Payload Webhook

POST https://your-server.com/webhook

Headers:
  Content-Type: application/json
  X-CRMHUB-Signature: sha256=abc123...

Body:
{
  "event": "message.received",
  "timestamp": "2026-06-02T08:30:00Z",
  "data": {
    "conversation_id": 456,
    "contact": {
      "name": "Budi Santoso",
      "phone": "6281234567890"
    },
    "message": {
      "type": "text",
      "content": "Halo, saya mau tanya soal produk"
    },
    "channel": "whatsapp",
    "device_id": 2
  }
}

Verifikasi Signature Webhook

Setiap webhook request menyertakan header X-CRMHUB-Signature — berisi HMAC SHA-256 dari payload menggunakan Webhook Secret Anda. Selalu verifikasi signature ini untuk memastikan request benar-benar dari CRMHUB.

// Contoh verifikasi di Node.js
const crypto = require('crypto');

function verifyWebhook(payload, signature, secret) {
  const expected = 'sha256=' + crypto
    .createHmac('sha256', secret)
    .update(payload)
    .digest('hex');
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expected)
  );
}

Konfigurasi Webhook

Konfigurasi webhook di Settings → Webhook Outbound. Masukkan URL endpoint Anda, pilih event yang ingin diterima, dan simpan Webhook Secret untuk verifikasi.

Dokumentasi API Lengkap

Dokumentasi teknis lengkap dengan semua endpoint, parameter, dan contoh kode tersedia di halaman API Docs di dalam aplikasi:

  1. Buka menu Developer di sidebar.
  2. Klik tab "API Docs".
  3. Dokumentasi interaktif akan tampil — Anda dapat mencoba endpoint langsung dari browser (Swagger UI).
