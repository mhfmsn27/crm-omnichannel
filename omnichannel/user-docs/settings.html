⚙️ Pengaturan

Kelola seluruh konfigurasi workspace, automasi, customer service, integrasi, dan akun CRMHUB Anda.

Halaman Settings dapat diakses melalui menu sidebar atau dropdown di header aplikasi. Sebagian besar pengaturan hanya dapat diakses oleh Admin atau pengguna dengan izin yang sesuai.

ℹ️
Navigasi Sub-Menu Settings

Halaman Settings memiliki sub-menu di sebelah kiri yang dikelompokkan per kategori: Workspace, Automasi, Customer Service, AI & Bahasa, dan Integrasi. Klik kategori yang diinginkan untuk langsung berpindah.

Workspace

Pengaturan Umum Workspace

Konfigurasi identitas dan preferensi dasar bisnis Anda. Pengaturan ini berlaku untuk seluruh workspace dan terlihat oleh semua anggota tim.

PengaturanDeskripsi
Nama Workspace / BisnisNama bisnis Anda yang ditampilkan di header aplikasi dan laporan
Logo BisnisUpload logo perusahaan (format PNG/JPG, rekomendasi 200×200px). Muncul di header dan dokumen invoice
Zona Waktu (Timezone)Tentukan zona waktu default workspace — memengaruhi jadwal broadcast, jam operasional, dan timestamp laporan
Bahasa AntarmukaBahasa default tampilan aplikasi untuk semua pengguna (Indonesia / English)
Deskripsi BisnisKeterangan singkat tentang bisnis Anda (opsional, digunakan oleh AI Copilot sebagai konteks)
Alamat BisnisAlamat fisik yang muncul di footer invoice dan dokumen formal
  1. Buka Settings → Workspace → Pengaturan Umum.
  2. Isi atau perbarui field yang diinginkan.
  3. Upload logo baru dengan klik area gambar atau tombol "Ganti Logo".
  4. Pilih Zona Waktu dari dropdown — ketik nama kota untuk pencarian cepat.
  5. Klik Simpan. Perubahan berlaku langsung untuk seluruh workspace.

Notifikasi

Atur preferensi notifikasi agar Anda dan tim tidak melewatkan pesan atau event penting. Pengaturan notifikasi dapat dikustomisasi per agent melalui halaman profil masing-masing, namun Admin dapat mengatur default notifikasi workspace.

Jenis Notifikasi

EventNotifikasi
Pesan Masuk BaruNotifikasi browser + suara saat ada pesan masuk ke inbox Anda
Assign ke SayaNotifikasi saat percakapan di-assign ke akun Anda
Mention (@nama)Notifikasi saat Anda di-mention di internal note percakapan
SLA Hampir TerlewatPeringatan saat percakapan mendekati batas SLA
Broadcast SelesaiNotifikasi saat kampanye broadcast selesai dikirim
Pembayaran DiterimaNotifikasi saat payment link dilunasi pelanggan
  1. Buka Settings → Workspace → Notifikasi.
  2. Aktifkan atau nonaktifkan toggle untuk setiap jenis notifikasi.
  3. Pilih saluran notifikasi: Browser (push notification), Email, atau keduanya.
  4. Klik Simpan.
💡
Izin Notifikasi Browser

Untuk menerima notifikasi browser, pastikan Anda sudah mengizinkan notifikasi dari domain CRMHUB di browser. Klik ikon gembok (🔒) di address bar browser → "Notifikasi" → "Izinkan".

Pengaturan Inbox

Konfigurasi perilaku default inbox untuk seluruh workspace: pembuatan tiket otomatis, antrian percakapan, dan tampilan inbox.

PengaturanDeskripsi
Auto-Create TiketBuat tiket otomatis untuk setiap percakapan masuk baru (berguna untuk tracking CS)
Queue ManagementAktifkan mode antrian: percakapan masuk masuk ke antrian sebelum di-assign ke agent
Max Percakapan per AgentBatas maksimal percakapan aktif yang bisa ditangani satu agent secara bersamaan
Auto-Resolve IdleOtomatis resolve percakapan yang tidak ada aktivitas selama X hari
Pesan Selamat DatangPesan otomatis yang dikirim ke pelanggan pertama kali menghubungi
Pesan Di Luar Jam KerjaBalas otomatis saat percakapan masuk di luar jam operasional
  1. Buka Settings → Workspace → Pengaturan Inbox.
  2. Aktifkan Auto-Create Tiket jika ingin setiap percakapan masuk otomatis membuat tiket terlacak.
  3. Atur Max Percakapan per Agent sesuai kapasitas tim Anda (rekomendasi: 10–20).
  4. Set batas idle untuk Auto-Resolve (contoh: 3 hari tanpa respons).
  5. Tulis teks pesan selamat datang dan pesan di luar jam kerja jika diperlukan.
  6. Klik Simpan.

Team & Anggota

Kelola seluruh anggota tim: tambah agent baru, ubah role/level akses, dan hapus anggota yang tidak aktif. Lihat panduan lengkap di halaman Manajemen Tim.

Role & Akses

Buat dan kelola Custom Role dengan nama, tipe, level akses, dan izin granular yang bisa dikustomisasi sepenuhnya. Lihat panduan lengkap di halaman Role & Akses.

Quick Reply Global

Kelola template quick reply yang dapat digunakan oleh seluruh agent (bukan hanya pribadi). Quick reply global membantu standarisasi respons tim. Lihat panduan lengkap di halaman Templates & Quick Reply.

Lisensi Domain

Tampilkan status lisensi domain aktif untuk instalasi CRMHUB Anda. Halaman ini menampilkan:

  • Domain yang terdaftar dan status validitasnya
  • Tanggal aktivasi dan masa berlaku lisensi
  • Tombol untuk memperbarui / refresh validasi lisensi
⚠️
Lisensi Tidak Valid

Jika lisensi domain tidak valid, akses ke aplikasi akan dibatasi. Hubungi tim CRMHUB untuk aktivasi atau perpanjangan lisensi.

Automasi

Semua pengaturan automasi tersedia di sub-menu ini. Lihat panduan lengkap di halaman Automasi & Customer Service.

Auto Reply

Atur balasan otomatis berdasarkan kata kunci, kondisi pesan masuk, atau jam di luar operasional. Setiap aturan dapat diterapkan ke channel tertentu.

Auto Label

Tambahkan label secara otomatis ke percakapan masuk berdasarkan kondisi yang ditentukan — misalnya, label "Komplain" untuk pesan yang mengandung kata "kecewa" atau "refund".

Auto Archive

Arsipkan percakapan yang sudah tidak aktif secara otomatis setelah periode waktu tertentu, menjaga inbox tetap bersih.

Customer Service

Auto Assignment

Distribusikan percakapan masuk ke agent secara otomatis menggunakan mode Round Robin atau Load Balancing. Lihat panduan Auto Assignment.

Jam Operasional

Atur jadwal hari dan jam operasional bisnis beserta zona waktu. Digunakan oleh Auto Reply, Auto Assignment, dan perhitungan SLA. Lihat panduan Jam Operasional.

Kebijakan SLA

Buat standar waktu respons (First Response Time, Resolution Time) dan aktifkan notifikasi peringatan saat SLA hampir terlewat. Lihat panduan SLA.

AI & Bahasa

Multi-Language AI

Aktifkan deteksi bahasa otomatis agar chatbot dan sistem dapat memahami serta membalas pesan dalam berbagai bahasa secara cerdas. Mendukung Indonesia, Inggris, Mandarin, Arab, dan banyak lagi. Lihat panduan Multi-Language AI.

Integrasi

Payment Gateway

Hubungkan akun payment gateway untuk mengaktifkan fitur Payment Link di Inbox. CRMHUB mendukung Xendit sebagai gateway utama.

  1. Buka Settings → Integrasi → Payment Gateway.
  2. Pilih provider: Xendit.
  3. Masukkan Secret Key dari dashboard Xendit Anda.
  4. Klik "Test Koneksi" untuk verifikasi, lalu Simpan.
  5. Fitur Payment Link di inbox kini aktif dan siap digunakan.

E-Commerce

Hubungkan toko online Anda ke CRMHUB untuk mengakses data pesanan dan produk langsung dari inbox.

PlatformFitur yang Tersedia
ShopifySinkronisasi produk, lihat status order, link order ke percakapan
WooCommerceSinkronisasi produk, lihat status order
TokopediaLihat pesanan masuk
LazadaLihat pesanan masuk
  1. Buka Settings → E-Commerce.
  2. Klik "Tambah Koneksi" dan pilih platform toko Anda.
  3. Masukkan API Key / Store URL sesuai platform yang dipilih.
  4. Klik "Test Koneksi" untuk verifikasi, lalu Simpan.
  5. Produk dan pesanan akan tersinkronisasi secara otomatis.

Ongkir & Shipping

Integrasikan layanan pengiriman untuk mengecek ongkos kirim langsung dari chat, membantu agent memberikan informasi pengiriman tanpa berpindah aplikasi.

  1. Buka Settings → Ongkir & Shipping.
  2. Masukkan API Key dari penyedia layanan pengiriman (contoh: RajaOngkir).
  3. Simpan. Agent dapat mengecek ongkir menggunakan fitur cek ongkir di inbox.

Webhook Outbound

Kirim notifikasi event ke sistem eksternal Anda (CRM, ERP, atau aplikasi lain) setiap kali terjadi event tertentu di CRMHUB.

EventDeskripsi
message.receivedPesan masuk baru dari pelanggan
conversation.resolvedPercakapan ditandai selesai
conversation.assignedPercakapan di-assign ke agent
contact.createdKontak baru dibuat
payment.paidPayment link berhasil dibayar
  1. Buka Settings → Webhook Outbound.
  2. Klik "Tambah Webhook".
  3. Masukkan URL endpoint tujuan dan pilih event yang ingin dikirimkan.
  4. Simpan. Sistem mengirimkan payload JSON ke URL tersebut setiap kali event terjadi.

Lihat dokumentasi webhook lengkap beserta format payload di halaman Developer & API.

Email Channel

Sambungkan akun email (Gmail, Outlook, atau SMTP custom) sebagai channel tambahan di CRMHUB, sehingga email dari pelanggan masuk ke inbox bersamaan dengan chat WhatsApp dan platform lainnya.

  1. Buka Settings → Email Channel.
  2. Pilih provider email (Gmail, Outlook, atau SMTP Custom).
  3. Ikuti langkah autentikasi OAuth (untuk Gmail/Outlook) atau masukkan konfigurasi SMTP manual.
  4. Verifikasi koneksi dan Simpan.
  5. Email masuk akan muncul di inbox CRMHUB sebagai percakapan baru.
