📱 Progressive Web App (PWA 2.0) & Capacitor Native

Akses CRMHUB dari smartphone dengan pengalaman native: standalone full-screen, offline cache, homescreen shortcuts, getaran taktil, dan integrasi Android & iOS.

1. Cara Install CRMHUB di Smartphone (PWA)

🤖

Android (Chrome / Edge)

Buka URL web CRMHUB di browser Chrome. Klik banner melayang "Install CRMHUB App" atau pilih menu titik tiga ➔ "Tambahkan ke Layar Utama".

🍎

iPhone / iPad (Safari)

Buka URL di Safari, ketuk tombol Share (Bagikan) di bilah bawah, lalu pilih "Add to Home Screen (Tambah ke Layar Utama)".

2. Keunggulan Fitur Mobile CRMHUB 2.0

  • Tampilan Standalone — Berjalan tanpa address bar browser, terasa 100% seperti aplikasi native.
  • Mobile Bottom Navigation Bar — Navigasi 5 tab bawah ramah ibu jari (Inbox, Kontak, Sales GPS, Faktur, TV Mode).
  • Safe-Area Insets — Kompatibel penuh dengan poni kamera dan Dynamic Island iPhone (tidak tertutup notch).
  • App Shortcuts Homescreen — Tekan dan tahan ikon aplikasi CRMHUB di homescreen HP untuk jalan pintas cepat.
  • Getaran Taktil (Haptics Feedback) — Sensasi getar halus saat mengirim pesan atau beralih tab.

3. Panduan Build Native Android APK & iOS IPA (Capacitor)

Untuk developer/tim teknis yang ingin mengompilasi aplikasi menjadi file .apk / .aab (Google Play) atau .ipa (Apple App Store):

cd omnichannel/frontend

# 1. Tambahkan platform Android & iOS
npx cap add android
npx cap add ios

# 2. Sinkronkan build produksi
npm run build
npx cap sync

# 3. Buka di Android Studio / Xcode
npx cap open android
npx cap open ios
