DEVOPS GUIDE CRMHUB Omnichannel 2.0 Multi-Instance Setup
● Zero-Conflict Architecture

🚀 Panduan Instalasi Multi-Instance CRMHUB V2 di VPS yang Sama

Panduan praktis langkah-demi-langkah menginstall aplikasi CRMHUB Omnichannel V2 Terbaru pada server VPS Domainesia yang telah berjalan versi lama, menggunakan domain baru dari Rumahweb (crmhub.internatechtion.my.id) secara 100% terisolasi (folder, database, services, port, dan aset terpisah tanpa mengganggu versi lama).

🌐 Domain Baru: crmhub.internatechtion.my.id (Rumahweb) 🖥️ VPS Server: Domainesia Ubuntu (Single Host) 🔒 Domain Eksisting: crm.legalkreatif.my.id (Aman / Zero Downtime)
Lompat Cepat: 1. DNS Rumahweb 2. Database Postgres 3. Folder & Source Code 4. Config .env 5. Build & Migrasi 6. PM2 Services 7. Nginx & SSL 8. Lisensi RSA-2048

Konfigurasi DNS di Rumahweb (Pointing ke VPS Domainesia)

Menghubungkan subdomain crmhub.internatechtion.my.id ke IP Publik Server VPS Domainesia Anda.

ℹ️ Langkah di Dashboard Rumahweb Clientzone:
  1. Login ke Clientzone Rumahweb (https://clientzone.rumahweb.com).
  2. Masuk ke menu Domains ➔ List Domains ➔ Kelola Domain internatechtion.my.id.
  3. Pilih tab DNS Management (atau Zone Editor).
  4. Klik tombol Add New Record dengan rincian:
    • Record Type: A
    • Name / Subdomain: crmhub
    • TTL: 14400 (atau 3600)
    • RDATA / IP Address: [IP_PUBLIK_VPS_DOMAINESIA] (Contoh: 103.xxx.xxx.xxx)
  5. Klik Save Changes.

Verifikasi propagasi DNS di terminal laptop/komputer Anda:

Terminal / CMD 
ping crmhub.internatechtion.my.id
# Atau gunakan nslookup:
nslookup crmhub.internatechtion.my.id

Pembuatan Database & User PostgreSQL Terpisah

Membuat database baru crmhub_v2_db lengkap dengan ekstensi AI pgvector & pg_trgm.

Login ke SSH VPS Domainesia Anda menggunakan PuTTY / Terminal:

Bash (SSH VPS) 
# 1. Masuk ke prompt PostgreSQL
sudo -u postgres psql

# 2. Buat user dan database baru untuk CRMHUB V2
CREATE USER crmhub_user WITH PASSWORD 'PasswordKuatV2_123!';
CREATE DATABASE crmhub_v2_db OWNER crmhub_user;
GRANT ALL PRIVILEGES ON DATABASE crmhub_v2_db TO crmhub_user;

# 3. Hubungkan ke database baru dan aktifkan ekstensi
\c crmhub_v2_db
CREATE EXTENSION IF NOT EXISTS vector;
CREATE EXTENSION IF NOT EXISTS pg_trgm;
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

# 4. Berikan izin hak akses skema public
GRANT ALL ON SCHEMA public TO crmhub_user;

# 5. Keluar dari psql
\q

Menjalankan Services dengan PM2 Process Manager

Mendaftarkan 2 service baru ke PM2 dengan nama unik agar berdampingan aman dengan service lama.

Bash (SSH VPS) 
# 1. Jalankan Omnichannel Backend V2 (Port 8999)
cd /var/www/crmhub-v2/omnichannel/backend
pm2 start server.js --name "crmhub-v2-backend"

# 2. Jalankan WA Gateway V2 (Port 8001)
cd /var/www/crmhub-v2/wa-server/wa-gateway/wa-gateway-backend
pm2 start dist/server.js --name "crmhub-v2-wa-gateway"

# 3. Simpan daftar proses PM2 agar otomatis hidup saat server reboot
pm2 save

# 4. Periksa seluruh proses yang berjalan (Pastikan proses lama & baru sama-sama online)
pm2 list

Konfigurasi Nginx Reverse Proxy & SSL Let's Encrypt

Mengatur routing domain `crmhub.internatechtion.my.id` ke Port `8999` dan mengamankan HTTPS dengan Certbot.

Buat file konfigurasi Nginx baru: sudo nano /etc/nginx/sites-available/crmhub.internatechtion.my.id

/etc/nginx/sites-available/crmhub.internatechtion.my.id 
server {
    listen 80;
    server_name crmhub.internatechtion.my.id;

    client_max_body_size 50M;

    # Frontend Single Page App (SPA)
    location / {
        root /var/www/crmhub-v2/omnichannel/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # REST API Reverse Proxy ke Backend Port 8999
    location /api/ {
        proxy_pass http://127.0.0.1:8999;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket Socket.IO Realtime Engine
    location /socket.io/ {
        proxy_pass http://127.0.0.1:8999;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # Public Uploaded Assets
    location /uploads/ {
        proxy_pass http://127.0.0.1:8999;
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # Webhook Callbacks
    location /webhook/ {
        proxy_pass http://127.0.0.1:8999;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

Aktifkan konfigurasi Nginx dan pasang Sertifikat SSL HTTPS:

Bash (SSH VPS) 
# 1. Aktifkan symlink virtualhost
sudo ln -s /etc/nginx/sites-available/crmhub.internatechtion.my.id /etc/nginx/sites-enabled/

# 2. Uji sintaks Nginx (Pastikan output: syntax is ok & test is successful)
sudo nginx -t

# 3. Reload Nginx
sudo systemctl reload nginx

# 4. Pasang SSL Otomatis Let's Encrypt
sudo certbot --nginx -d crmhub.internatechtion.my.id
