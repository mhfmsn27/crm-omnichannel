Global Knowledge Base

Knowledge Base adalah "otak" chatbot Anda. Isi dengan informasi bisnis, FAQ produk, kebijakan layanan, dan dokumen referensi — bot akan menjawab pertanyaan pelanggan berdasarkan data ini.

Menambah Q&A

  1. Buka Chatbot → Global Knowledge Base.
  2. Klik "+ Tambah Q&A".
  3. Isi kolom Pertanyaan — Masukkan pertanyaan yang sering diajukan pelanggan.
  4. Isi kolom Jawaban — Masukkan jawaban yang ingin diberikan bot.
  5. Klik Simpan. Bot akan mulai menggunakan data ini.
💡
Tips Q&A yang Efektif

Gunakan variasi pertanyaan yang sama (sinonim). Contoh: "berapa harganya", "harga produk", "biaya berapa" — semua bisa dijawab dengan satu entri jawaban. Bot AI dapat memahami maksud yang serupa.

Upload Dokumen Referensi

Unggah dokumen PDF, Word, atau TXT sebagai sumber pengetahuan bot. Sistem akan mengekstrak teks dari dokumen dan menggunakannya untuk menjawab pertanyaan.

  1. Di halaman Knowledge Base, klik tab "Dokumen".
  2. Klik "Upload Dokumen" dan pilih file (maks. 10MB per file).
  3. Tunggu proses ekstraksi selesai.
  4. Dokumen siap digunakan sebagai referensi bot.

Flow Builder (Alur Percakapan Visual)

Flow Builder memungkinkan Anda merancang alur percakapan chatbot secara visual menggunakan antarmuka drag-and-drop — tanpa perlu menulis kode satu baris pun.

Apa itu Flow?

Flow adalah serangkaian langkah percakapan yang terstruktur. Contoh: Pelanggan mengetik "menu" → Bot menampilkan pilihan → Pelanggan memilih "Info Harga" → Bot membalas dengan daftar harga.

Cara Membuat Flow Baru

  1. Buka Chatbot → Flows.
  2. Klik "+ Buat Flow" dan beri nama (contoh: "Flow Pemesanan", "Flow FAQ").
  3. Anda akan masuk ke kanvas Flow Builder.
  4. Tambah Node Trigger — Tentukan pemicu flow: kata kunci tertentu, pesan pertama, atau waktu tertentu.
  5. Tambah Node Pesan — Drag node "Kirim Pesan" ke kanvas dan isi dengan teks/gambar yang dikirim bot.
  6. Tambah Node Pilihan — Drag node "Pilihan" untuk membuat menu pilihan. Hubungkan setiap pilihan ke node berikutnya.
  7. Tambah Node Kondisi — Opsional: node "Kondisi" memungkinkan flow bercabang berdasarkan data kontak atau input pelanggan.
  8. Hubungkan Node — Tarik garis dari satu node ke node berikutnya untuk menentukan urutan alur.
  9. Simpan & Aktifkan — Klik Simpan lalu aktifkan flow agar mulai berjalan.

Konfigurasi Bot

Setiap perangkat WhatsApp dapat memiliki bot tersendiri dengan pengaturan yang berbeda.

  1. Buka Chatbot → Daftar Bot.
  2. Klik "+ Buat Bot" atau klik bot yang sudah ada untuk mengedit.
  3. Beri nama bot dan pilih perangkat yang terhubung.
  4. Atur sumber jawaban: Knowledge Base, Flow aktif, atau keduanya.
  5. Atur kondisi aktif: selalu aktif, hanya di luar jam kerja, atau jadwal tertentu.
  6. Simpan dan aktifkan bot.

AI Training

Tingkatkan akurasi bot secara berkelanjutan dengan melatihnya menggunakan percakapan nyata yang sudah terjadi.

Cara Melatih Bot

  1. Buka Chatbot → AI Training.
  2. Lihat daftar percakapan yang direkomendasikan untuk pelatihan — ini adalah percakapan di mana bot tidak menjawab dengan baik atau tidak tahu jawabannya.
  3. Untuk setiap percakapan, klik "Tambah ke Training".
  4. Edit pertanyaan dan jawaban sesuai kebutuhan.
  5. Klik Simpan. Data training ditambahkan ke Knowledge Base.

Selain manual, Anda juga dapat mengimpor data training secara massal menggunakan file CSV.

API Key Chatbot

CRMHUB menyediakan API Key untuk mengintegrasikan chatbot dengan sistem eksternal atau menggunakannya dalam pengujian (Sandbox).

  1. Buka Chatbot → API Key.
  2. Salin API Key yang ditampilkan untuk digunakan di sistem eksternal.
  3. Klik "Perbarui API Key" untuk membuat key baru jika key lama bocor atau perlu diganti.
  4. Gunakan fitur Sandbox untuk menguji respons bot sebelum diluncurkan ke pelanggan nyata.
⚠️
Jaga Keamanan API Key

Jangan pernah membagikan API Key ke pihak yang tidak berwenang. Jika API Key bocor, segera buat key baru melalui halaman API Key.
