🔧 Pemecahan Masalah

Panduan langkah demi langkah untuk mengatasi masalah umum di CRMHUB — dari koneksi WhatsApp hingga error login dan broadcast.

💡
Sebelum Memulai

Pastikan browser Anda sudah diperbarui ke versi terbaru dan koneksi internet stabil. Banyak masalah umum terselesaikan hanya dengan refresh halaman (Ctrl+Shift+R) atau membersihkan cache browser.

WhatsApp Tidak Bisa Terhubung

⚠️
Gejala: Status perangkat tetap "Menunggu" atau "Terputus" setelah scan QR. QR Code tidak muncul atau terus berputar.
  1. Periksa koneksi internet kedua sisi — Pastikan ponsel WhatsApp dan server VPS memiliki internet yang stabil. Coba buka website di browser ponsel untuk konfirmasi.
  2. Hapus semua sesi WhatsApp Web — Di ponsel: WhatsApp → Perangkat Tertaut → hapus SEMUA sesi aktif → tunggu 30 detik.
  3. Scan QR Code baru — Muat ulang halaman Integrations di CRMHUB (tekan F5) dan scan QR yang baru muncul. QR berlaku 60 detik.
  4. Restart perangkat WhatsApp di CRMHUB — Di halaman Integrations, klik tombol Restart pada perangkat yang bermasalah.
  5. Periksa status WA Gateway server — Jika Anda admin, cek apakah proses WA Gateway masih berjalan: pm2 status di server.
  6. Coba di waktu berbeda — WhatsApp kadang memblokir sementara jika terlalu banyak percobaan scan. Tunggu 10–15 menit lalu coba lagi.

WhatsApp Tiba-tiba Terputus

⚠️
Gejala: Perangkat yang sebelumnya terhubung tiba-tiba menjadi Disconnected saat sedang digunakan.
  1. Scan QR ulang — Ini cara paling cepat. Scan QR baru dari halaman Integrations.
  2. Cek apakah ponsel digunakan orang lain — Jika ada yang membuka WhatsApp di ponsel utama dan mengakhiri sesi web, koneksi akan putus.
  3. Periksa apakah WhatsApp diupdate — Update versi WhatsApp kadang memutus semua sesi perangkat tertaut. Scan ulang diperlukan.
  4. Cek apakah ponsel mengalami gangguan internet — Koneksi yang tidak stabil di ponsel bisa memutus WA Gateway.

Broadcast Gagal Terkirim

⚠️
Gejala: Status pesan di laporan broadcast menunjukkan "Gagal" atau "Error". Beberapa pesan terkirim, sebagian tidak.
  1. Periksa status perangkat pengirim — Pastikan perangkat WhatsApp yang digunakan berstatus Connected (hijau) di halaman Integrations.
  2. Periksa format nomor tujuan — Nomor harus format internasional tanpa tanda + (contoh: 6281234567890, bukan 081234567890 atau +6281234567890).
  3. Cek isi pesan — Hindari kata-kata yang sering ditandai spam. Jangan kirim link yang sama ke banyak orang sekaligus.
  4. Periksa Device Rotator — Jika menggunakan rotator, pastikan semua perangkat dalam rotator terhubung dengan baik.
  5. Kurangi kecepatan pengiriman — Jika banyak pesan gagal, coba atur delay antar pesan lebih lama di pengaturan broadcast.
  6. Periksa apakah nomor valid — Gunakan Number Checker untuk validasi nomor sebelum broadcast.

Masalah Login

⚠️
Gejala: Tidak dapat masuk meskipun memasukkan email dan password yang benar. Muncul pesan "Invalid password" atau "User not found".
  1. Pastikan Caps Lock tidak aktif — Password bersifat case-sensitive. Cek apakah Caps Lock menyala.
  2. Gunakan fitur Lupa Password — Klik "Lupa Kata Sandi" di halaman login, masukkan email, cek kotak masuk (dan folder Spam).
  3. Hapus cache dan cookie browser — Buka pengaturan browser → Privacy → Hapus data browsing → centang Cache & Cookie → hapus.
  4. Coba browser berbeda — Gunakan Chrome, Firefox, atau Edge versi terbaru.
  5. Nonaktifkan ekstensi browser — Beberapa ekstensi (ad blocker, VPN) bisa mengganggu proses login.
  6. Reset password via script — Jika Super Admin lupa password, jalankan node reset-password.js di server backend untuk reset manual.

Chatbot Tidak Merespons

⚠️
Gejala: Pesan pelanggan tidak dijawab otomatis oleh chatbot meskipun sudah dikonfigurasi.
  1. Cek apakah chatbot diaktifkan — Buka Chatbot → Global Knowledge. Pastikan toggle Aktif dalam keadaan ON.
  2. Cek pengaturan per perangkat — Setiap perangkat WhatsApp harus diaktifkan chatbot-nya secara terpisah di Integrations → [nama perangkat] → Bot Settings.
  3. Pastikan perangkat terhubung — Chatbot hanya bisa membalas jika ada perangkat WhatsApp yang Connected.
  4. Tambah variasi pertanyaan — Jika chatbot tidak mengenali pertanyaan, tambahkan variasi kata di Knowledge Base. Bot AI butuh beberapa contoh kalimat yang berbeda.
  5. Periksa apakah percakapan sudah di-assign ke agent — Jika percakapan sudah di-assign ke agent dan agent sedang Online, chatbot tidak akan merespons agar tidak mengganggu agen yang aktif.

Pesan Tidak Masuk ke Inbox

⚠️
Gejala: Pelanggan sudah mengirim pesan tapi tidak muncul di Inbox CRMHUB.
  1. Refresh halaman Inbox — Tekan F5 atau Ctrl+R. Pesan mungkin sudah masuk tapi tampilan belum terupdate.
  2. Periksa filter aktif — Pastikan tidak ada filter yang menyembunyikan percakapan. Klik tab Semua untuk tampilkan semua percakapan.
  3. Cek status perangkat — Jika perangkat Disconnected, pesan tidak akan masuk. Reconnect perangkat terlebih dahulu.
  4. Cek apakah masuk ke archived — Pesan dari kontak yang pernah diarsipkan bisa langsung masuk ke tab Terarsip.
  5. Restart WA Gateway — Jika admin server: pm2 restart wa-gateway untuk refresh koneksi.

Notifikasi Tidak Muncul

⚠️
Gejala: Tidak ada notifikasi browser atau suara saat pesan baru masuk.
  1. Aktifkan izin notifikasi browser — Klik ikon gembok 🔒 di address bar browser → pilih Izinkan Notifikasi untuk domain CRMHUB.
  2. Pastikan tab CRMHUB tidak diminimize ke system tray — Browser yang diperkecil ke systray kadang menghambat notifikasi.
  3. Periksa pengaturan "Jangan Ganggu" OS — Windows Focus Assist atau macOS Do Not Disturb bisa memblokir notifikasi.
  4. Cek volume sistem — Pastikan volume komputer tidak di-mute.

Upload File Gagal

⚠️
Gejala: Tidak bisa upload foto, dokumen, atau file dari Inbox. Muncul error saat upload.
  1. Periksa ukuran file — WhatsApp memiliki batas ukuran file. Gambar max ~5MB, dokumen max ~100MB, video max ~16MB.
  2. Periksa tipe file — Beberapa tipe file tidak didukung WhatsApp. Gunakan format umum: JPG, PNG, PDF, DOCX, MP4.
  3. Cek ruang penyimpanan server — Jika admin: df -h untuk cek disk usage. Full disk menyebabkan upload gagal.
  4. Periksa konfigurasi Nginx — Batas upload di Nginx default 1MB. Tambahkan client_max_body_size 100M; di config Nginx jika perlu.

Aplikasi Terasa Lambat

  1. Bersihkan cache browser — Data cache yang menumpuk bisa memperlambat loading halaman.
  2. Periksa resource server — Jika admin: htop atau top untuk cek CPU dan RAM. Jika penuh, pertimbangkan upgrade server.
  3. Kurangi jumlah percakapan yang dimuat — Arsipkan percakapan lama yang sudah resolved agar inbox lebih ringan.
  4. Periksa koneksi database — Jalankan query lambat mungkin membutuhkan optimasi index PostgreSQL.
  5. Cek Redis connection — CRMHUB menggunakan Redis untuk caching. Pastikan Redis berjalan: redis-cli ping harus menjawab PONG.

Masalah Invoice

MasalahSolusi
Invoice tidak terkirim ke pelangganPeriksa status perangkat WhatsApp. Pastikan nomor pelanggan terdaftar di WhatsApp. Cek log invoice untuk pesan error.
Format angka tidak sesuaiPastikan pengaturan mata uang dan format angka sudah benar di Settings → Invoice Settings.

Payment link tidak berfungsiPeriksa konfigurasi payment gateway (Xendit/Tripay/Doku) di Settings → Integrasi Pembayaran.
