Setup WA Gateway Self-Hosted
di VPS yang Sama dengan CRMHUB

Panduan lengkap menginstal dan mengintegrasikan WA Gateway (non-official WhatsApp via Baileys) ke CRMHUB yang sudah berjalan di VPS yang sama — tanpa konflik port, database, atau Nginx.

Daftar Isi
— Pengantar & Arsitektur — Pra-Instalasi: Cek Port & Konflik 01 Upload Kode Gateway ke VPS 02 Setup Database PostgreSQL (Terpisah) 03 Konfigurasi File .env Gateway 04 Build TypeScript & Jalankan via PM2 05 Konfigurasi Nginx & SSL untuk Gateway 06 Update Konfigurasi Backend CRMHUB 07 Verifikasi Integrasi & Test Koneksi WA — Troubleshooting — Diagram Alur Kerja

○ Pengantar & Arsitektur

WA Gateway adalah server Node.js terpisah yang menangani koneksi WhatsApp non-official menggunakan library Baileys. CRMHUB berkomunikasi dengannya via REST API — mengirim pesan, menerima pesan via webhook, dan mengelola sesi QR scan.

ℹ️
Komponen yang Diinstal
Hanya satu komponen yang perlu diinstal: wa-gateway-backend (server REST API). Tidak perlu menginstal wa-admin-frontend untuk integrasi CRMHUB — frontend admin gateway hanya untuk manajemen SaaS multi-tenant yang tidak diperlukan di sini.
⚠️
WhatsApp Non-Official — Risiko Yang Perlu Dipahami
Koneksi via Baileys bukan API resmi Meta. WhatsApp dapat men-ban nomor yang dianggap melanggar ToS. Gunakan nomor dedikasi untuk bisnis, bukan nomor personal. Jangan kirim spam/broadcast massal dalam jumlah besar sekaligus.

01 Upload Kode Gateway ke VPS

Folder yang perlu diupload dari komputer lokal Anda adalah wa-server/wa-gateway/wa-gateway-backend/. Tujuan di VPS: /var/www/wa-gateway/.

Opsi A — Upload via SCP (dari Windows PowerShell)

PowerShell — jalankan di komputer Windows Anda
# Ganti YOUR_VPS_IP dan YOUR_USER sesuai VPS Anda
scp -r "D:\Web Dev Project Apps\CRMHUB OMNICHANNEL\wa-server\wa-gateway\wa-gateway-backend" YOUR_USER@YOUR_VPS_IP:/var/www/wa-gateway/

# Contoh dengan root:
scp -r "D:\Web Dev Project Apps\CRMHUB OMNICHANNEL\wa-server\wa-gateway\wa-gateway-backend" root@123.456.789.10:/var/www/wa-gateway/

Opsi B — Upload via FileZilla / WinSCP (GUI)

  1. Buka FileZilla atau WinSCP, hubungkan ke VPS dengan kredensial SSH Anda
  2. Di sisi kiri (lokal), navigasi ke D:\Web Dev Project Apps\CRMHUB OMNICHANNEL\wa-server\wa-gateway\
  3. Di sisi kanan (VPS), navigasi ke /var/www/
  4. Buat folder baru wa-gateway di VPS
  5. Drag-and-drop folder wa-gateway-backend dari lokal ke /var/www/wa-gateway/

Setelah upload — verifikasi di VPS

bash — SSH ke VPS

ls /var/www/wa-gateway/wa-gateway-backend/

# Output yang diharapkan:
package.json  package-lock.json  src/  tsconfig.json  pm2.config.js

02 Setup Database PostgreSQL (Terpisah dari CRMHUB)

✅
Database CRMHUB tidak diubah sama sekali
Gateway menggunakan database terpisah (wa_gateway_db) dengan user berbeda (wa_user). Database omni_db milik CRMHUB tidak disentuh.

2.1 — Buat database dan user baru

bash — SSH ke VPS, jalankan sebagai root
sudo -u postgres psql

Setelah masuk ke prompt psql, jalankan SQL berikut. Ganti PASSWORD_BARU_ANDA dengan password yang kuat:

sql — di dalam psql prompt
-- Buat user baru untuk gateway (JANGAN gunakan omni_user)
CREATE USER wa_user WITH ENCRYPTED PASSWORD 'PASSWORD_BARU_ANDA';

-- Buat database baru
CREATE DATABASE wa_gateway_db;

-- Berikan akses penuh
GRANT ALL PRIVILEGES ON DATABASE wa_gateway_db TO wa_user;
ALTER USER wa_user WITH SUPERUSER;

-- Hubungkan ke database baru
\c wa_gateway_db

-- Aktifkan extension UUID
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- Tabel untuk admin sistem gateway
CREATE TABLE admins (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    username VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Tabel untuk API client (CRMHUB terdaftar di sini)
CREATE TABLE clients (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    name VARCHAR(255) NOT NULL,
    webhook_url TEXT,
    api_key VARCHAR(255) UNIQUE NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Tabel untuk sesi WhatsApp
CREATE TABLE sessions (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    client_id UUID REFERENCES clients(id) ON DELETE CASCADE,
    name VARCHAR(255) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Tabel untuk menyimpan auth state Baileys (session persistence)
CREATE TABLE baileys_sessions (
    client_id VARCHAR(255) NOT NULL,
    session_key VARCHAR(255) NOT NULL,
    session_data JSONB,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (client_id, session_key)
);

-- Keluar dari psql
\q

2.2 — Generate API key dan daftarkan CRMHUB sebagai client

API key ini akan digunakan di dua tempat: wa_gateway_db (tabel clients) dan CRMHUB backend/.env. Generate dulu:

bash — generate random API key
# Generate API key 64 karakter (simpan outputnya!)
openssl rand -hex 32

# Contoh output: a3f8c9d2e1b7654321fedcba9876543210abcdef1234567890abcdef12345678
# Salin dan simpan string ini — akan dipakai di langkah berikutnya

Sekarang daftarkan CRMHUB sebagai client di database gateway. Ganti nilai-nilai berikut:

  • YOUR_API_KEY — hasil generate dari perintah di atas
  • https://app.yourdomain.com — domain CRMHUB Anda (bukan subdomain gateway)
bash — daftarkan CRMHUB sebagai client gateway
sudo -u postgres psql -d wa_gateway_db -c "
INSERT INTO clients (name, webhook_url, api_key)
VALUES (
  'CRMHUB',
  'https://app.yourdomain.com/webhook/wa-gateway',
  'YOUR_API_KEY'
);
"

# Verifikasi berhasil dibuat:
sudo -u postgres psql -d wa_gateway_db -c "SELECT id, name, webhook_url, LEFT(api_key,16)||'...' AS api_key FROM clients;"
⚠️
Catat CLIENT ID yang muncul
Setelah INSERT berhasil, jalankan perintah SELECT di atas. Catat nilai id (UUID) dari baris client CRMHUB — nilai ini dibutuhkan di langkah berikutnya untuk konfigurasi CRMHUB_WEBHOOK_URL (sebenarnya tidak perlu manual karena sudah otomatis, tapi berguna untuk debugging).

03 Konfigurasi File .env Gateway

Buat file .env di dalam folder wa-gateway-backend:

bash
nano /var/www/wa-gateway/wa-gateway-backend/.env

Isi dengan konfigurasi berikut. Sesuaikan semua nilai yang disorot:

.env — /var/www/wa-gateway/wa-gateway-backend/.env
# ─────────────────────────────────────────────
# WA GATEWAY BACKEND — Environment Configuration
# ─────────────────────────────────────────────

NODE_ENV=production

# Port gateway — WAJIB berbeda dari CRMHUB (8998)
SERVER_PORT=8080

# Koneksi ke database gateway (BUKAN database CRMHUB)
# Ganti PASSWORD_BARU_ANDA dengan password wa_user yang dibuat di Langkah 2
DATABASE_URL=postgres://wa_user:PASSWORD_BARU_ANDA@localhost:5432/wa_gateway_db

# JWT Secret — minimal 32 karakter, generate dengan: openssl rand -hex 32
JWT_SECRET=GANTI_DENGAN_STRING_ACAK_MIN_32_KARAKTER

# ─────────────────────────────────────────────
# INTEGRASI CRMHUB — konfigurasi webhook
# ─────────────────────────────────────────────
# URL webhook CRMHUB: format https://DOMAIN_CRMHUB_ANDA/webhook/wa-gateway
# Ganti dengan domain CRMHUB Anda yang sudah live
CRMHUB_WEBHOOK_URL=https://app.yourdomain.com/webhook/wa-gateway

# ─────────────────────────────────────────────
# PROXY (Opsional — kosongkan jika tidak pakai)
# ─────────────────────────────────────────────
PROXY_ENABLED=false
# PROXY_HOST=
# PROXY_PORT=
# PROXY_USERNAME=
# PROXY_PASSWORD=
VariableKeterangan
SERVER_PORTPort gateway. Harus 8080, berbeda dari CRMHUB port 8998
DATABASE_URLKoneksi ke wa_gateway_db. Ganti PASSWORD_BARU_ANDA dengan password wa_user dari Langkah 2
JWT_SECRETSecret untuk admin panel gateway. Generate: openssl rand -hex 32
CRMHUB_WEBHOOK_URLAlamat webhook CRMHUB. Format: https://<domain-crmhub>/webhook/wa-gateway
PROXY_ENABLEDIsi false kecuali VPS Anda butuh proxy untuk akses WhatsApp
⚠️
Setelah selesai edit, simpan dan tutup nano
Tekan Ctrl+X → Y → Enter untuk menyimpan file di nano.

05 Konfigurasi Nginx & SSL untuk Gateway

✅
Nginx CRMHUB tidak diubah
Kita hanya menambahkan server block baru untuk subdomain gateway. Konfigurasi CRMHUB yang sudah ada di /etc/nginx/sites-enabled/ tidak disentuh sama sekali.

5.1 — Buat server block untuk subdomain gateway

Ganti gateway.yourdomain.com dengan subdomain yang sudah Anda arahkan ke VPS ini:

bash — buat file config baru
nano /etc/nginx/sites-available/wa-gateway
nginx — /etc/nginx/sites-available/wa-gateway
# WA Gateway — server block terpisah dari CRMHUB
server {
    listen 80;
    server_name gateway.yourdomain.com;  # ← ganti dengan subdomain Anda

    client_max_body_size 50M;

    location / {
        proxy_pass         http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header   Upgrade $http_upgrade;
        proxy_set_header   Connection 'upgrade';
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 120s;

        add_header 'Access-Control-Allow-Origin'  $http_origin always;
        add_header 'Access-Control-Allow-Methods' 'GET, POST, PUT, DELETE, OPTIONS' always;
        add_header 'Access-Control-Allow-Headers' 'Content-Type, Authorization' always;
        add_header 'Access-Control-Allow-Credentials' 'true' always;

        if ($request_method = 'OPTIONS') {
            add_header 'Access-Control-Allow-Origin'  $http_origin always;
            add_header 'Access-Control-Allow-Methods' 'GET, POST, PUT, DELETE, OPTIONS' always;
            add_header 'Access-Control-Allow-Headers' 'Content-Type, Authorization' always;
            add_header 'Content-Type' 'text/plain; charset=utf-8';
            add_header 'Content-Length' 0;
            return 204;
        }
    }
}

5.2 — Aktifkan dan test konfigurasi

bash
# Aktifkan server block gateway
ln -sf /etc/nginx/sites-available/wa-gateway /etc/nginx/sites-enabled/

# Test konfigurasi nginx (pastikan tidak ada error)
nginx -t

# Output yang diharapkan:
nginx: the configuration file /etc/nginx/nginx.conf syntax is ok
nginx: configuration file /etc/nginx/nginx.conf test is successful

# Reload nginx (BUKAN restart — agar koneksi CRMHUB tidak terputus)
systemctl reload nginx

5.3 — Pasang SSL untuk subdomain gateway

bash — pasang SSL hanya untuk subdomain gateway

# Atau jika sudah punya email terdaftar di certbot sebelumnya:

○ Troubleshooting

Gateway tidak mau start (port 8080 sudah dipakai)

bash — cek proses yang menggunakan port 8080
lsof -i :8080
# Jika ada proses lain, ganti SERVER_PORT di .env gateway (misal: 8081)
# Dan update juga proxy_pass di nginx dari 8080 ke 8081

Error: FATAL: Invalid environment variables

🚨
Penyebab: .env tidak ada atau ada variabel yang hilang
Cek: cat /var/www/wa-gateway/wa-gateway-backend/.env
Pastikan DATABASE_URL, JWT_SECRET, dan SERVER_PORT terisi semua. Nilai JWT_SECRET minimal 32 karakter.

Error koneksi database: password authentication failed

bash — test koneksi database manual
# Test koneksi dengan user wa_user
psql -U wa_user -d wa_gateway_db -h localhost -c "SELECT 1;"
# Masukkan password wa_user yang dibuat di Langkah 2
# Jika gagal: password di .env salah atau user belum dibuat

401 Unauthorized saat CRMHUB memanggil gateway

bash — verifikasi api_key di database
sudo -u postgres psql -d wa_gateway_db -c "SELECT name, LEFT(api_key,20)||'...' AS api_key, webhook_url FROM clients;"

# Pastikan api_key di tabel clients SAMA PERSIS dengan WA_GATEWAY_API_KEY di .env CRMHUB

QR code tidak muncul di CRMHUB (status terus "creating")

bash — cek webhook delivery
pm2 logs wa-gateway --lines 50
# Cari baris: "[Webhook]" — apakah ada error saat kirim ke CRMHUB?

# Kemungkinan penyebab:
# 1. CRMHUB_WEBHOOK_URL di .env gateway salah
# 2. APP_URL di .env CRMHUB masih "http://localhost:3000"
# 3. Firewall VPS memblokir loopback ke port CRMHUB (8998)

# Test webhook delivery manual (dari VPS):
curl -X POST -H "Content-Type: application/json" \
  -d '{"test":true}' \
  http://localhost:8998/webhook/wa-gateway
# Expected: 200 OK (endpoint aktif)

Error saat npm install (gyp error / build tools)

bash
# Baileys membutuhkan build tools untuk beberapa dependensi native
apt install -y build-essential python3

# Coba install ulang
cd /var/www/wa-gateway/wa-gateway-backend
rm -rf node_modules package-lock.json
npm install

Perintah PM2 berguna lainnya

bash — cheat sheet PM2
# Restart gateway setelah perubahan .env
pm2 restart wa-gateway

# Rebuild dan restart setelah update kode
cd /var/www/wa-gateway/wa-gateway-backend
npm run build && pm2 restart wa-gateway

# Monitor real-time
pm2 monit

# Lihat semua proses (CRMHUB + gateway)
pm2 list

# Auto-start saat reboot (jalankan sekali)
pm2 startup && pm2 save

       │ POST webhook { event: "session.status.update", status: "NEED_QR" }
       ▼
  CRMHUB Backend
       │ GET /api/v1/sessions/:uuid/status → { qr: "..." }
       │ emit Socket.IO "qr_received" ke browser
       ▼
  Admin CRMHUB (browser)
       │ QR code tampil di layar
       │ scan dengan HP → WhatsApp terhubung
